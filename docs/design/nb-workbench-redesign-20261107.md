# 数学实验室按 NB 重做：世界模型 + 界面（2026-11-07）

原型：`apps/web/lab-nb.html`（单文件、无构建，直接用浏览器打开）。
本文说明：现在为什么差得远、新的世界模型长什么样、界面怎么排、怎么并回主 App。
只借 NB 的机制和布局思路，文案、图形、代码全部是自己的。

## 1. 为什么现在“差十万八千里”——根上的 3 个错

| | NB 实验室 | 我们现在（v0.9） |
|---|---|---|
| 世界是什么 | **一张台面 + 台上任意多个器材实例 + 器材之间的连线**。引擎对“任意摆法”都算得出结果 | 一组**固定槽位**：`tenframe{A,B}`、`balance{L,R}`、一条 `numline`、一条 `linefn`、一个 `rect`、一个 `dice`……每种只有一个，不能放两台天平、两条数轴 |
| 器材怎么来 | 右边器材架拖到台上，台上的东西就是器材本身 | 页面里预先排好的 8 张卡片（worldFracCard / worldBalCard…）+ 6 个数的“台面”；器材不能拖到任意位置，也不能互相接 |
| 器材之间怎么交流 | 连线（导线、导管）：A 的输出接到 B 的输入，引擎沿连线算 | 靠 `piece.at` 把一个数“放进”某个槽位；数值不能从分数条流到合并器再流到数轴 |
| 界面 | 全屏实验界面：顶栏 / 中间深色画布（缩放、平移）/ 右侧器材架 / 选中后旁边出设置卡 / 练习有步骤栏、考试有计时和提交 | 一个长网页里的一节：模式行、问题卡片、8 张器材卡、调试 dump（`worldDerivedOut`）、旧工作间、托盘、三张组合台、四个工具小站，上下滚着找 |

所以不是“UI 皮不好看”，而是**模型是“每题一套槽位”，界面是“一页小部件”**。在这个底子上再加功能，只会越加越像网页，不会像 NB。

## 2. 新的统一数学世界（原型里已实现）

### 2.1 世界 = 场景图

```
scene = {
  entities: { id: { id, type, name, x, y, props } },   // 台上任意多个器材实例
  links:    [ { id, from, to, slot } ],                 // 输出 → 输入（天平有左/右 slot）
  seq, nid                                              // 编号（分数条1、分数条2…）
}
```

- 没有“每题一个世界”：实验只是**一份摆好的 scene + 一组步骤**；自由探究就是一份空 scene。
- 所有改动只走 `act(intent)`：校验 → 改 → 引擎重算。不合法的直接拒绝并说原因（分母 0、越界、连成圈、直线连到天平……），拒绝次数计入考试的“被拒绝”。
- 全部可序列化（JSON）：撤销/重做、自动保存、保存/分享实验都是同一份数据。

### 2.2 器材注册表 TYPES（一个器材 = 一行）

每种器材声明：`label / group / out（输出类型）/ accepts（接收类型）/ fields（2–4 个可调属性，带范围）/ actions / size / DRAW`。
加一个新器材 = 加一行注册 + 一个画法 + 引擎里一段规则，不碰别的代码。

原型里 9 种：数字卡、分数条、合并器、数轴、天平、直线、坐标平面、长方形、两个骰子。
端口类型两种：`value`（精确有理数）和 `fn`（直线）。类型不对连不上——这就是数学版的“接错线”。

### 2.3 引擎 evaluate(scene) → derived（纯函数，唯一算后果的地方）

- 数值沿连线流动：分数条/数字卡产出值 → 合并器求和（精确分数，可级联）→ 数轴/天平消费。
- 每个器材得到 `read`（读数）和 `sig`（信号：ok / info / warn / err），**台面在器材下方直接画信号条**：
  “7 放不下：数轴只从 0 到 2”“左边重 1/4”“分母不同：都换成 6 份再加”“k 一样：两条线平行”“交点 (1/2, 2)”。
- 错了不打红叉：器材描红边 + 后果画出来（天平倾斜、点落在不同位置、直线不过目标点）。
- 没有“运行”按钮，每次操作立刻重算。

### 2.4 实验 = 摆法 + 带分值的步骤

```
{ id, title, domain, grade, tools, q, why, build(scene), steps:[{label, score, hint, target(scene), check(scene, derived)}] }
```

- 步骤按顺序判：只有“刚做了一次操作 + 前面步骤已得分 + 现在台面状态满足 check”才给分；开场摆好的状态不算分。
- 练习：左栏显示步骤和提示，下一步要动的器材在台面上发光；做完弹“再练一次 / 进入考试 / 返回实验库”，并解锁“为什么”。
- 考试：隐藏步骤和提示，顶栏 10 分钟倒计时 + 红色“提交”；提交后出报告：得分、每步得分、丢分位置、用时、操作数、被拒绝数；写进跨次统计（考过几次、最近得分、最常丢的一步）。
- 原型里 5 个实验：分数相加、天平平衡、k 变负数、周长一定面积最大、两个骰子点数和。

## 3. 界面（照 NB 的骨架，原型里已实现）

```
┌ 顶栏：≡ | 数学实验室 | 实验名(可改) | [自由探究|练习|考试] | 菜单(练习) ……… 撤销 重做 整理 清空 | ⏱(考试) 提交(考试) ┐
├ 左栏(可收起) ─┬──────────── 深色网格画布（拖空白平移，滚轮/按钮缩放 50%–250%）────────────┬ 器材架 ─┤
│ 实验库 | 步骤 │   器材卡片：标题 + 实物画法 + 右侧蓝色输出端口 / 左侧输入端口           │ 搜索     │
│ 搜索+领域筛选 │   连线：贝塞尔曲线 + 流动虚线                                           │ 按组两列 │
│ 实验详情：    │   选中：虚线框 + 右侧竖条工具（设置/复制/旋转/删除）+ 设置卡              │ 拖到台上 │
│ 练习 / 考试   │   设置卡：名字、当前状态、滑杆+数字+±、动作按钮、恢复初始值              │ 或点一下 │
│ 考过N次…      │   信号条：器材下方，绿/橙/红                                            │          │
│               │ 左下：− 100% + 适应            右下：💡为什么  📝我的发现               │          │
└───────────────┴─────────────────────────────────────────────────────────────────────────┴──────────┘
```

四种手势 = 操作词典：点整体（选中/开设置卡）、点部位（点分数条的格子改分子）、拖整体（移动）、拖端口（连线）；拖空白 = 平移。
键盘：Delete 删除、Ctrl+Z / Ctrl+Y。窄屏（<900px）隐藏器材架。

## 4. 并回主 App 的步骤

1. **入口**：首页“实验室”入口直接打开全屏工作台（`lab-nb.html` 或 `index.html#lab` 全屏层），不再在长页面里滚。
2. **拆文件**：原型的三层直接拆成 `lab-world.js`（Q、TYPES 规则、act、evaluate、实验与步骤，纯函数，可 node 测）+ `lab-view.js`（DRAW、手势、设置卡）+ `lab.css`。`tools/smoke-lab-world.js` 测 act/evaluate/步骤判分。
3. **迁移旧模型**：`math-world.js` 里已有的规律逐个变成器材规则——十格阵、鸡兔（头/腿两个输入 + 可行性信号）、由两点定直线、整数校验、骰子公平（A/B 分组）。`LAB_PROCEDURES` 的 5 个流程改写成新的 steps；`math-lab-proc-v1` 统计口径保留。
4. **删掉**：8 张固定器材卡、`worldDerivedOut` 调试 dump、旧托盘 + 三张组合台、四个工具小站、`labSync*` 双份状态。
5. **接上**：考试丢分步骤 → 错题本（按步骤记，不只记知识点）；“我的发现”接 `math-inquiry-v1`；实验库按知识点挂到年级单元页“动手试一试”。
