# XP Lint 升级设计文档

日期：2026-11-08。  
起因：`node tools/check-xp.js` 输出"检查 88 个实验：通过 15，不过 73"。  
目标：**73 个不过的实验全部 lint 通过**，不改任何已通过实验的逻辑。

---

## 0. 问题诊断

运行 check-xp 的完整输出显示 73 个实验有以下两类失败：

| 失败原因 | 数量（大约） |
|---|---|
| 只有 2 步，要求至少 3 步 | 69 |
| 没有预测步 | 73 |

两类通常同时出现（一个实验同时缺少步骤数量和预测步）。只有少数实验（如 g4_15、g5_7）有 3 步，但仍缺预测步。

**15 个已通过实验的共同特征：**
- 有 `type:'predict'` 步骤（步骤标签里含"预测"或"猜"）
- 共 3 步或以上
- 例子：`g4_4`（预测 → 连线 → 验算）、`g3_12`（预测 → 改参数 → 验证面积）、`fracadd`（4 步，无预测但有 4 步）

---

## 1. 解决方案：三步标准模板

每个不过的实验改成：

```
步骤 0：预测步（type:'predict'，score:1）
步骤 1：操作步（已有的 s1，保持原 check 不变，改 id 为 s1）
步骤 2：验证步（已有的 s2 或新写，保持原 check 不变，改 id 为 s2）
```

**预测步统一格式：**
```js
{id:'xpId:s0', type:'predict', expect: <数字>, label:'先猜一猜：答案是多少？',
 score:1, hint:'先算一算，写下你的预测，再点"猜好了"。',
 target: T45('主器材'), check:()=>false}
```

- `expect` 填实验的正确答案（整数）
- `type:'predict'` 使得 lint 中"预测步"检测通过（check-xp 检查 label 含"预测"即可）
- `check:()=>false` 预测步永不自动完成，等学生点"猜好了"
- 已有步骤的 id 从 `s1` 开始，不打乱原有步骤顺序

## 3. 不该改的部分（红线）

1. **已过 lint 的 15 个实验不动**：fracadd、balfrac、funcline、maxarea、dice、g4_4、g4_10、g3_12、g5_1、g5_5、g5_9、g4_15、g5_7、g4_1、g4_2（部分已过）
2. **check 谓词不改**：现有 check 函数只要不改逻辑，不影响基线
3. **不引入新器材类型**：只在 XP 数据里加步骤，不动 TYPES / DRAW / evaluate
4. **步骤 ID 规则遵守**：格式 `xpId:sN`，N 从 0 开始递增，不重复
5. **why 不改**：已通过 lint 规则 3（讲推理），不需要改

## 4. 分批计划

每批改一个 P 数组，不跨组。每批结束跑一次 check-xp.js 确认进度。

| 批次 | 目标 P 数组 | 实验数 | 预期通过数 |
|---|---|---|---|
| Batch A | P45（已改的子集之外） | ~11 | 11 |
| Batch B | P46、P47、P48 | ~8 | 8 |
| Batch C | P49、P3、P3B | ~12 | 12 |
| Batch D | WPO/WPT（应用题组）| ~9 | 9 |
| Batch E | g6_* 组 | ~13 | 13 |
| Batch F | g7_* / g8_* / g9_* 组 | ~20 | 20 |

验收：check-xp.js 通过数 = 88（目前 15），不过数 = 0。

## 4.5 施工注意（评审后补）

**`restoreRun` index 偏移问题：** `restoreRun` 按数组 index（i）读 `sv.steps`，插入 s0 后老存档的 index=0 对应原来的 s1，状态会错位。处理方案：在 `restoreRun` 里跳过 predict 步（`if(xp.steps[i].type==='predict')return`），让 predict 步总是从未完成状态开始，不从存档恢复。这样旧存档的 s1→s2 完成状态仍然对应 index=1/2，偏移消除。

## 5. 已知风险

| 风险 | 影响 | 处理 |
|---|---|---|
| 预测步的 expect 值填错 | 学生填对了却不被认可 | 逐一核算或搭台面验算后填写 |
| id 序号冲突（s0 已存在） | lint 报"步骤没有 id" | 每个 P 数组改之前先搜 s0 是否已存在 |
| 函数生成型实验（clock2、wt06 等）步骤用函数生成 | check-xp 跳过（"未内联步骤"），不算不过 | 不用改，维持跳过即可 |
| g5_4（骰子）预测步 expect=7 但学生填的是字符串 | 类型不匹配？ | 看 predict 步骤的处理逻辑，必要时用 7（数字） |

---

## 6. 验收标准

```
node tools/check-xp.js
检查 88 个实验：通过 88，不过 0；未内联步骤（跳过）N
```

跳过数（N）不变或减少（函数生成型实验如被改成内联后会减少，但不要求改）。
