# 器材属性：有没有更好的设计

日期：2026-11-08 00:40 JST。问题：Iris 说“器材的属性太少”，又叫停了我直接改（“你不要改”），要求先分析有没有更好的设计。这篇只分析，不改代码。分析对象：`lab-nb.html` 的 TYPES + 设置卡 + `act('set')`（代码核对过），以及 NB 原版属性面板（2026-11-07 真机走访验证过的形态）。

## 1. 先说结论：有，而且“多加几个字段”是最差的那种好

现在的设计是“一把滑杆走天下”：每种器材的属性 = `TYPES.fields` 里的一串 `{k, label, min, max, step}`，设置卡按这个清单通用渲染（滑杆 + 数字框 + ± 按钮）。这个机制本身没错，NB 也是“点物体 → 旁边出设置卡 → 字段行”的形态。

但只加字段治标不治本，因为问题不只在数量：

- **控件不对**。选择只有 2–3 个值也用滑杆：`mirror`（0 不做，1 做）是滑杆，`view`（0 正面，1 侧面，2 上面）是滑杆，`rot`（0/90/180/270）是滑杆。学生拖滑杆选“做不做轴对称”，又慢又容易滑过头。
- **没有推导值**。卡里只显示能改的，不显示改了之后算出来的。圆的卡里有半径，没有周长和面积（那两个只在器材下面的信号条里）；三角形的卡里有两个角，没有第三个角。学生调的时候，眼睛要在卡和器材之间来回跳。
- **关系约束没有统一原则**。数轴是“拒绝式”：`max-min` 小于 1 或大于 20 就拒绝，理由写得很好（“最右要比最左大”）。三角形是“允许后报错式”：两个角可以滑到 150+150，引擎在信号条报“两个角已经 300°，超过 180°，画不出三角形”。两套哲学混在一个台面上，没人写下来哪种情况用哪种。
- **0 属性的 5 种器材，这个机制没有答案**。合并器、乘法器、除法器、天平、坐标平面的卡里只有名字 + 一行灰色小字（“它的值由连进来的器材决定”）。不是它们没属性可调，是机制只认“数字字段”，装不下“运算是加还是减”“商写成分数还是带余数”这种属性。
- **物上直接调几乎没有**。只有分数条能点某一段改分子（`segclick`），其他所有属性都只能在卡里调。Iris 的原则是“在物体上调（拖拽手柄）”，现在只有卡，没有手柄。
- **卡会盖住台面**。卡是浮动定位，复测里已经出现两次盖住器材（新拖上来的合并器一半在器材架下面；“整理”后设置卡盖住分数条）。属性一多，卡更长，更容易盖。
- **被拒绝也算错**。`act('set')` 被拒绝时，练习/考试模式会让 `run.errors++`，考试报告里的“被拒绝 N 次”会把“滑杆拖过头”算进去。滑杆拖过头不是数学错。

顺带纠正一个复测里的误读：测试员说合并器设置卡里有“运算 ＋、显示格式”，代码里没有——`adder.fields` 是空数组，那是合并器画出来的内容（“1/2 ＋ 1/3 = 5/6”），不是能调的控件。0 个属性这个数是对的。

## 2. 三种设计，对比

### A. 同型扩字段：只加字段，机制不动

就是我刚才叫停的那个方案：给 10 种 0/1 属性的器材补字段，每种到 2–4 个。

- 好处：最便宜，改动只在 TYPES + `evaluate` + DRAW；设置卡不用动；风险最低。
- 坏处：第 1 节的问题一个都没解决。`mirror` 还是滑杆，圆的卡还是没有周长，除法器还是装不下“带余数”，天平还是 0 属性（除非硬塞两个数字字段）。数量达标了，体验还是同一套。
- 结论：可以做，但不能只做这个。

### B. 分型属性卡（推荐先做这个）

卡还在，点物体还在旁边出卡，但属性分三类，每类用对的控件：

| 属性种类 | 意思 | 控件 | 例子 |
|---|---|---|---|
| 状态值 | 这个器材的数学状态本身 | 滑杆 + 数字框（现状保留）/ 步进器 | 分子、分母、半径、k、b |
| 显示方式 | 同一个值换一种写法 | 分段按钮（2–4 个选项，不要用滑杆） | 分数/小数/百分数；商写成分数/小数/带余数 |
| 行为约束 | 这个器材怎么响应 | 拨动开关 / 步进器 | 约分开/关；盘容量；灵敏度；锁定 |

再加三条：

- **只读行**：推导出来的值放在卡里，不让改，但让学生看见。圆的卡：半径下面一行“周长 18.84 厘米，面积 28.26 平方厘米”；三角形的卡：第三个角一行“第三个角是 110°”；长方形的卡：现在 `stateLine` 已经有“3 × 4 = 12”，把它正式变成只读行。
- **拒绝说明常驻**：拒绝时除了 toast（2.6 秒就没了），在卡里对应字段下面留一行红字说明原因（“分母不能是 0”“最右要比最左大”）。学生调错了能立刻知道为什么，不用等 toast。
- **卡片停靠**：卡不要浮在台面上盖器材，停靠在右侧器材架下方或左侧实验库下方，固定位置；太长了内部滚动。

### C. 物上直接调（NB 和 Polypad 的做法，第二批做）

手柄长在物体上，卡退居二线（只显示数值 + 少数拖不出来的属性）：

- 长方形：拖角改宽长（拖对角）；拖边旋转。
- 圆：拖圆周上的点改半径。
- 角：拖一条边改度数。
- 数轴：直接拖点改值（已经有点的概念，缺拖）。
- 分数条：点某一段改分子（已经有了，保留）。
- 直线：拖直线本身改 b，拖斜率手柄改 k。

NB 验证过的形态就是这个方向：选中 = 高亮框 + 圆形旋转手柄 + 竖条小工具栏；数字用小键盘输；浮动标签常驻关键值（分数条显示“3/4”）。这套最像 NB，但工作量最大，风险也最大——每一步判分都检查 props，拖拽必须走同一条 `act()` 路径提交，否则“拖出来了但没得分”。

**推荐顺序：B 先做（一批），C 只做 5 个最常用的手柄（下一批）。A 单独做没有意义。**

## 3. 24 种器材的属性表（按设计 B）

“现在 → 推荐”：只列要变的部分；3 个属性的 6 种（人民币、条形图、折线图、鸡兔笼、图形、扇形图）基本不动，只改控件类型或可选加第 4 组。

| 器材 | 现在 | 推荐属性（类型 / 范围 / 改了能看到什么） |
|---|---|---|
| 数字卡 | 1：值 | 值（步进器，−10..20，现有）；**步长**（分段 1/2/5/10，± 按钮一次走几格）；**锁定**（开关，锁住后学生改不了——实验预设值用，第二批） |
| 分数条 | 2：分子、分母 | 现有 2 个；**显示**（分段：分数/小数/百分数，标签和读数跟着变） |
| 合并器 | 0 | **运算**（分段：＋/－，算出的结果从和变差；默认 ＋，现有实验步骤都假设 ＋）；**显示**（分段：分数/小数，结果读数跟着变） |
| 乘法器 | 0 | **约分**（开关：4/6 显示为 2/3 还是 4/6）；**显示**（分段：分数/小数） |
| 除法器 | 0 | **商的形式**（分段：分数/小数/带余数——7÷2 = 7/2 / 3.5 / 3余1，这是除法本身的核心概念）；**验算**（开关：显示 3×2+1=7） |
| 人民币 | 3 | 不变（元/角/分已够） |
| 钟面 | 2：时、分 | 现有 2 个；**秒**（步进器 0–55 step 5，第二根针） |
| 角 | 1：度数 | 度数（现有）；**边长**（步进器 1–5 格，臂画多长）；**起始方向**（分段 0/90/180/270，整个角转着画） |
| 条形统计图 | 3 | 现有 3 个；可选 **四班**（步进器，第四根柱，低优先级） |
| 三角形 | 2：两个角 | 现有 2 个；**底边长**（步进器 1–8 格，画多大）；第三个角放只读行 |
| 平行四边形 | 2：底、高 | 现有 2 个；**倾斜角**（步进器 30–150°，斜着画——同底同高面积不变，这是平行四边形的核心概念） |
| 折线统计图 | 3 | 现有 3 个；可选 **第四年**（步进器，低优先级） |
| 鸡兔笼 | 3 | 不变 |
| 数对 | 2：列、行 | 现有 2 个；**网格大小**（步进器 4–10，平面画多大） |
| 图形（平移/旋转/对称） | 3 | 数量不变，控件改型：旋转改分段按钮（0/90/180/270），对称改开关 |
| 立体图形 | 1：方向 | 方向改分段按钮（正面/侧面/上面，不用滑杆）；**透明**（开关：透过看藏着的方块） |
| 圆 | 1：半径 | 半径（现有）；**π**（分段 3.14/3.1416，周长面积的数跟着变；默认 3.14，g6_5 的步骤检查按默认走）；**显示**（分段：周长/面积/都要） |
| 扇形统计图 | 3 | 现有 3 个；可选 **四班**（步进器，低优先级） |
| 数轴 | 2：最左、最右 | 现有 2 个；**刻度间隔**（分段 0.5/1/2，刻度线跟着变——分数需要 0.5 的刻度） |
| 天平 | 0 | **盘容量**（步进器 2–8，默认 5；现在连线时硬编码“一个盘最多放 5 个”，要改成读属性）；**灵敏度**（分段：每差 1 倾斜几度，横梁倾斜幅度跟着变） |
| 直线 | 2：k、b | 现有 2 个；**定义域**（步进器 \|x\|≤N 1–10，线段画多长） |
| 坐标平面 | 0 | **x 范围**（步进器 ±N 2–10，网格和直线跟着变）；**y 范围**（同上）；**网格**（开关：显示/隐藏） |
| 长方形 | 2：宽、长 | 现有 2 个；**角度**（步进器 0–359 step 15，任意角度旋转；现在旋转按钮只换宽长，要改画法） |
| 两个骰子 | 1：次数 | 次数（现有）；**骰子个数**（步进器 1–3，和的分布跟着变）；**面数**（分段 6/8/12，和的分布跟着变；掷的引擎现在写死 2 颗 6 面，要改 `roll` 和 `evaluate` 里的 `counts` 数组） |

每种最终 2–4 个，不超过 4 个。统计图的第 4 组（条形/折线/扇形）三处都是“可选、低优先级”，先不做也行。

## 4. 关系约束：定一条原则，不要混着来

现状两套并存，要统一：

- **硬不可能 → 拒绝并说明原因**。分母 0、数轴 max ≤ min、连线成圈、类型接错——这些现在已经是拒绝式，理由写得很好（“最右要比最左大”“不能连成一个圈”），保留。
- **可修复的错状态 → 允许，信号条报错**。三角形两角超过 180°、扇形三个班加起来超过 100%——错的状态本身就是一节课（g6_7 就是故意让学生先调错再修好）。这时候不要拒绝，要让错的状态画出来、报出来，学生修好了信号条变绿。
- **跨字段校验有先例**：数轴的 `max-min` 检查就是跨字段的（在 `act('set')` 里读了整个 props 对象）。三角形、扇形照这个 pattern 加。
- **属性调整被拒绝，不计入考试错误**：`run.errors++` 只计数学操作被拒绝，不计滑杆拖过头。否则考试报告的“被拒绝 N 次”会把调参数的手滑算成错。

## 5. NB 原版能抄的（真机验证过的，不是推测）

- 选中 = 高亮框 + 圆形旋转手柄 + 竖条小工具栏（图层/翻转/设置/删除）。
- 设置卡 = 名称（前缀 + 编号）+ 字段行 + 旋转角度；底部两个按钮：“作为默认”和“使用初始值”。数学台面现在有“恢复初始值”，缺“作为默认”（下次再拖同种器材就用这个值）。
- 数字用小键盘输（平板上比数字输入框好用）；浮动标签常驻关键值。
- **预设制**：DIY 流程是“先设参数，再做实验”。数学版对应：实验可以声明“本实验里某器材的某属性范围收窄”（比如分数相加实验里分母只许 2–6），即 per-XP 范围覆盖。这是第二批的事，先把 B 做完再说。
- 环境参数也可调（NB：重力、空气阻力）。数学版对应：台面级参数，比如数轴默认范围、分数是否自动约分。第三批，最低优先级。

## 6. 风险清单（动手的人必须先读）

- **步骤判分**：很多步骤检查精确的 props 和信号文字。g5_5 按插入顺序取第二张数字卡；g6_5 检查圆的信号文字（默认 π=3.14 时的 18.84/28.26）；g6_7 检查扇形信号。加属性改了信号文字或判分逻辑，必须同步改步骤检查。
- **旧存档**：自由探究自动保存（`nb-lab-free-v1`）里的旧场景没有新字段；新字段必须有 defaults 兜底，加载时 normalize。
- **卡片高度**：4 个属性 + 只读行 + 名字 + 按钮，卡会很长；现在卡片 `top` 钳在 `H-320`，要内部滚动或折叠。
- **长方形角度、骰子面数/个数**：这两个要改 DRAW 和引擎，不是只加字段，工作量比别的属性大，排在同批的后面。
- **不要加装饰性属性**：颜色、大小（除非是数学意义上的大小，比如角的边长）不算属性。每个新属性必须回答：改了它，图上或读数上有什么变化？答不上来就不加。
