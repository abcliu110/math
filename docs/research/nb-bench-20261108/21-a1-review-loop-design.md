# A1 学习闭环：练习写记录（设计）

日期：2026-11-08 18:05 JST。对应总清单 A1（练习模式不写任何记录）。只改逻辑，不改界面。

## 问题

练习模式做完（或做对）之后，什么记录都不写：错题本、今天复习、家长端一无所知。
只有考试交卷才写记录（`labNbExam` → `math-lab-proc-v1` + 挑战报告）。
练习的自动保存（`nb-lab-practice-v1`）只保场景、不记成绩，刷新后能接着做，但不产生任何学习记录。

## 两份存储的分工（现状，不改）

- `math-review-v1`（复习库，按知识点）：`recordAttempt(pointId, correct, confident)`。
  错 → 明天；对但不自信 → 明天；对且自信 → 3 天；连对 ≥2 次 → 7 天。
  今天复习、错题本、家长端本周小结、首页复习数，全读这一份。
- `math-lab-proc-v1`（跨次统计，按实验）：只记考试。`实验痕迹`显示“考过 N 次”。
  **本次不碰**：练习不写进这一份，“考过 N 次”的含义保持只算考试。

## 设计：练习完成时发一条消息，主页面记进复习库

### 台面侧（lab-nb.html）

`practiceDone()` 里发消息（与 `labNbExam` 同一个模式）：

```js
{type:'labNbPractice', payload:{
  labId: xp.id, title: xp.title,
  score: score(), max: tot,
  opCount: run.ops, errorCount: run.errors || 0,
  usedMs: Date.now() - run.t0,
  lines: xp.steps.map((s,i)=>({
    id: s.label,
    got: run.steps[i].done && (s.type!=='predict' || run.steps[i].pred===s.expect),
    op: run.steps[i].op
  }))
}}
```

- 只在完成时发一次：`run.practicePosted` 守卫（`practiceDone` 只在 `run.finished` 后调一次，
  再加守卫防重复）。
- `got` 的含义：普通步骤完成即对；**预测步只有猜对了才算对**——练习里唯一真正的“丢分”
  就是猜错（其余步骤做不对就一直做下去，没有失败态）。
- `op` 是该步完成时的操作数（费了多少劲的信号，供以后按步显示用）。
- 没做完就离开的不记：自动保存（PR）负责接着做；没有结果，就没有记录。

### 主页面侧（app.js）

新 `labNbPractice(p)` + `message` 监听（与 `labNbExam` 的监听同一个写法，
只认 `e.source === labNbFrame.contentWindow`）：

1. 按 `LAB_POINT_XP` 反查 `pointId`（与 `labNbRecord` 同一段循环）。
   查不到的（非知识点实验、原型、应用题）跳过——没有知识点可复习。
2. `correct = p.lines.every(l => l.got)`（即预测全对；普通步骤完成时全对）。
   `confident = (p.errorCount === 0)`（一次都没被台面拒绝）。
   调 `recordAttempt(pointId, correct, confident)`：
   - 猜错 → 当错记，明天复习， streak 清零。
   - 做对但被拒过 → 当“对但不自信”，明天复习。
   - 干净做对 → 3 天；连对 ≥2 次 → 7 天（走现有语义，不改规则）。
3. 把按步的结果以附加字段存进复习记录（`reviewStore[pointId].steps`），
   供以后按步显示用；**现在没有任何界面读它**。旧记录没有这个字段，照常工作。

## 这次不做的（诚实说明）

- **按步显示**：复习库是按知识点的，`今天复习`/`错题本`现在只能显示“这个知识点要复习”，
  显示不出“丢的是第几步”。按步显示要改存储的读法和这两页的渲染，是界面工作，不在这次做。
  本次只做到“按步写、按题显”：步的成绩写进去了，显示先按题。
- **中途放弃不记**：没完成就没有成绩；自动保存保证回来能接着做。
- **练习不进跨次统计**：`实验痕迹`的“考过 N 次”仍只算考试；家长端通过`本周小结`
  （读复习库）看到练习。

## 验收（真机）

1. 带预测步的实验，先猜错、再做完 → 该知识点出现在今天复习里（明天到期）。
2. 干净做完（无拒绝、预测对）→ 不出现在今天复习里（3 天后到期）。
3. 家长看这里 → 本周小结，练过的知识点计数 +1。
4. 练习流程本身不变：完成弹框、再练一次、进入考试、返回实验库都正常；做完不报错。
5. `实验痕迹`的“考过 N 次”不因练习而变（练习不写跨次统计）。
