# 类似数学 App 全网调研报告（含 GitHub 开源项目）

- 调研日期：2026-11-06
- 调研对象：全球类似数学学习 App + GitHub 开源数学项目
- 前置阅读：NB实验室调研（`~/workspace/research_notes/nb-lab-20261106/report.md`）、NB数学实验调研（`~/workspace/research_notes/nb-math-lab-20261106/report.md`）
- 版权声明：本报告只记录**机制层面**的观察与公开资料的转述，**不复制任何产品的文案、图片、界面、代码**。开源项目的代码复用必须遵守其许可证（第 5 节有逐项说明）；商业闭源产品只学机制。

---

## 0. 核心结论（先说最重要的发现）

**NB实验室那套方法（自由沙盒 + 错误可视化 + 分步评分 + 练习/考试双模式 + 教师/家长端 + 探究作业），在数学 App 里没有一家完整做出来。** 每个机制都有单项做得最好的产品，但都是散的：

- **自由沙盒**：Mathigon Polypad（30+ 教具自由拼）和 PhET（先探索再提问）是标杆；我们已经有数学实验室，处于同一档。
- **错误可视化**：ST Math（错了就把错误的逻辑动画演出来，不给红叉）是标杆；Graspable Math（非法操作物理上做不出来，拖过去会抖回来）是第二标杆。
- **分步评分**：**全网没有一家真正做"按步骤给分 + 丢分定位"**。最接近的是 Zearn 的 Boost（错了拆成小步重做）、Mangahigh 的分步解析、DreamBox 的隐形策略追踪——都是"分步讲解"，不是"分步给分"。这是我们能第一个做出来的空白点。
- **练习 vs 考试模式**：Symbolab 的 Practice（有提示）/ Quiz（无提示）分得最干净；Khan 的练习 vs 单元测试/ mastery 挑战是第二干净的模型。
- **教师/家长端**：ASSISTments（错题到题、到共性误解的实时报告，两次大型 RCT，ESSA 最高级）和洋葱教师版（布置 + 实时学情 + 试卷库）是两个标杆。
- **探究作业**：**全网没有一家真正做**。最接近的是火花的"小老师讲题"视频（孩子录视频讲思路）和 Zearn 的纸面作业——都是表达任务，不是探究作业。这是第二个空白点。
- **证据强度**：效果证据最硬的是 Zearn、DreamBox、IXL、Khan（ESSA Tier 1，RCT，效应量 0.10–0.17 SD，都很小）；DragonBox 12+ 和 Graspable Math 各有一个 N=1,850 的 RCT；绝大多数中国 App 没有任何对照研究，只有家长口碑和营销数字。
- **开源**：能直接复用的库有 5 个（JSXGraph、KaTeX、mathjs、MathLive、ts-fsrs，全部 MIT/Apache 友好许可证）；最值得学的机制模型是 Oppia（按具体错答分支反馈）和 PhET（先探索后提问）；PhET 和 Mathigon 的内容在 2026 年都已收紧许可证，**只能学机制，不能复用代码或内容**。

## 1. 国际可视化 / 交互工具

### 1.1 Mathigon / Polypad（Amplify）——免费沙盒标杆

- **是什么**：免费交互数学平台；Polypad 是"数学游乐场"，30+ 虚拟教具（分数条、数棒、代数瓷砖、数轴、七巧板、天平、骰子/转盘、3D 多面体展开）。K–12，网页 + 移动端，**免费**，不用登录就能玩。
- **自由沙盒**：空白画布上随便拖教具，自动吸附对齐；分数条 + 数轴 + 天平可以一起用，演示"为什么通分后才能加分数"。
- **错误可视化**：天平教具——只在一边加东西，天平真的歪了；要恢复平衡必须在另一边做同样的事。教师活动甚至故意不用对勾，让学生拿瓷砖图对照答案自己反思。
- **分步评分**：无。**练习/考试模式**：无。**教师/家长端**：免费教师账号：建班、布置、学生画布自动出现在教师仪表盘、可限制工具栏、链接分享画布；家长账号可看进度。
- **探究作业**：课程按"预测 → 实验 → 讨论"设计，如三角形不等式：随机断一根 10cm 的线，预测能拼成三角形的概率，做实验，全班数据汇总成表和图（约 25% 能拼成）。
- **证据**：弱。没有 Polypad 自己的 RCT；教师指南引用的是虚拟教具的通用研究（Hunt et al. 2011），不是 Polypad。教师口碑很好，但那是采用率，不是学习效果。
- **来源**：https://mathigon.org/polypad · https://polypad.amplify.com · 视频：https://www.youtube.com/watch?v=0cPLQtX6v2o

### 1.2 GeoGebra——动态几何 + 最完整的考试模式

- **是什么**：免费动态数学套件（几何、代数、作图、3D、CAS、表格、统计、概率）+ 100 万+ 社区素材 + GeoGebra Classroom。小学到大学，4–12 年级最重；网页 + 全平台 App；**非商业使用免费**；2025 年被 BYJU'S 收购。
- **自由沙盒**：拖一个顶点，整个图形、代数视图、图像同时联动更新——猜想检验（"什么变了，什么不变？"）。
- **错误可视化**：间接的——错误的猜想会"看得见地"让图形崩掉或图像对不上预测；另有拍照解题器给分步解答。
- **分步评分**：无。教师看到的是学生作品的实时缩略图，不是分步分数。
- **练习 vs 考试模式——全网最完整的考试模式**：GeoGebra 计算器考试模式：锁定设备（飞行模式 + 关 Wi-Fi/蓝牙 + 应用自锁）、从空白视图开始、计时（顶栏变绿）、退出时把考试详情截图存到相册；任何解锁尝试顶栏变红报警。Windows 有"参加考试"模式锁定整台电脑。
- **教师/家长端——GeoGebra Classroom（五家里直播监控最强）**：教师建班发代码；总览显示谁开始了、每人在哪一题、每个学生作品的实时缩略图（点开看大图）；选择题答案汇总成实时柱状图；开放题可匿名展示；PAUSE 按钮冻结全班；可隐藏姓名。接入 Google Classroom。
- **证据**：弱/混合。2025 年一篇开放综述是教学法 survey，不是实验，没有效应量。没有 GeoGebra Classroom 的 RCT。采用率极高（自称 1 亿+师生）。
- **来源**：https://www.geogebra.org · https://en.wikipedia.org/wiki/GeoGebra · https://www.geogebra.org/m/xtrcprek

### 1.3 Desmos（现 Amplify Desmos）——延迟反馈 + 讨论

- **是什么**：免费作图计算器 + 几何工具 + Desmos Classroom（Activity Builder，几千个现成活动）。K–12，初中/高中代数和函数最强；网页 + App；**完全免费，无付费层**；美国 SAT/PSAT 内置 Desmos 计算器。
- **自由沙盒**：作图计算器 + 滑杆：输入 `y = a·x + b`，拖滑杆看直线实时移动；学生还能用方程画画、做动画。
- **错误可视化——标志性做法是"延迟反馈 + 讨论"，不是即时红绿**：Card Sort（卡片分类）：学生把方程卡拖到图像卡配对；**教师仪表盘**显示正确配对绿色、错误红色、哪张卡最常配错——但学生本人不被告知对错，必须自己推敲。Polygraph（"猜猜我是谁"）：两人用"是/否"问题（斜率、截距）猜对方的图，错误在对话里暴露。教师可暂停全班、投影匿名学生作品、当场讨论误解。
- **分步评分**：无。**练习/考试模式**：Classroom 里无考试模式；计算器有 SAT 用的锁定版。
- **教师/家长端**：Desmos Classroom 仪表盘：实时看每个学生的图/答案；快照/汇总/教师/学生视图；匿名化姓名（换成数学家名字）；暂停 + 节奏控制；个别书面反馈；活动库可按年级/主题检索、复制改编。无家长仪表盘。
- **证据**：弱到中等，只有小样本研究：菲律宾 50 名八年级学生（Desmos 组解题能力提升显著高于直接教学）、23 名十一年级学生（前后测 t = −3.78，显著）、链式法则案例（n=25，96% 能展示形式化思维）。都是小样本、短期、低档期刊——仅供参考。最硬的证据是采用率：教师口碑、SAT 采用、巨大活动库。
- **来源**：https://www.desmos.com · 视频：https://www.youtube.com/watch?v=8c7Xpv99nvE · https://www.youtube.com/watch?v=HToTcxmOHPM

### 1.4 Brilliant.org——提示阶梯 + 解释"为什么错"

- **是什么**：交互式解题平台（数学、CS、科学、数据），约 12 岁到成人；数学从预代数到线性代数/数论。网页 + App。**免费增值**：免费层每天 1 课/2 把钥匙；Premium 约 $12.49/月（年付，约 $150/年）或 $24.99/月；家庭约 $40/月（6 席）；教师可申请免费 Premium。1000 万+ 注册用户。
- **自由沙盒**：有限。没有开放画布；每课是一连串小交互：拖切线、移滑杆、摆弄图形、再答题。沙盒在题目里面，不是一个自由空间（五家里最弱——我们的 app 已经超过它）。
- **错误可视化——提示优先，解释在后**：答错 → 提示往正确推理上推，**不给答案**；提交后完整解释说明"为什么这个错答案是错的"。2026 年 5 月新 AI 导师 Koji 能看到屏幕上的交互，标出/重排它，提引导问题，绝不透露答案。有评测提到 Brilliant 会让学习者打字解释"为什么自己错了"。具体例子：切线拖到错误的斜率 → 提示这点的斜率意味着什么 → 再试。
- **分步评分**：无按步部分分；但课程结构本身就是分步脚手架——每道题是概念的一小步，所以"按步"内嵌在课程设计里。
- **练习 vs 考试模式**：无考试模式。每课有练习集（去掉提示和可视化）；自适应引擎预测下一道最优题，用**间隔重复（薄弱处）**和**交叉练习**（混合概念，逼你自己选方法）——这两点直接对应我们已有的间隔复习 + 混着练。
- **教师/家长端**：个人无家长仪表盘；家庭计划可一起学；教师账号（免费 Premium）。游戏化层：连胜（每天 3 题或 1 课）、XP、30 人周联赛（10 个元素名段位：氢 → 锿）、徽章。
- **证据**：弱到中等。最好的一项研究：de la Puente & Perez（2025，准实验，哥伦比亚 60–70 名 10/11 年级学生，线性代数）：Brilliant 组测试分数 +15%、理解 +20%。小样本、单主题、非随机。Brilliant 自家的 Koji 数据（94% 求助后又尝试、66% 随后答对、87% 下一题答对）是行为数据，**不是对照研究**（Brilliant 自己也这么说）。用户口碑：应用商店 4.7★（11 万+ 评论）；常见抱怨：贵、技巧覆盖薄、长期用户对游戏化疲劳。无 RCT。
- **来源**：https://brilliant.org · https://eric.ed.gov/?id=EJ1473924

### 1.5 AoPS（Alcumus + Beast Academy）——竞赛数学 + "反通过"复习

- **是什么**：竞赛数学专家，1993 年创立。两条线：**Beast Academy**（1–5 年级，漫画指南 + 练习册 + 在线平台）和 **AoPS Online**（5–12 年级：预代数 → 微积分、数论、奥赛；教材 + 直播课 + 免费 Alcumus + 免费视频 + 社区）。网页；Beast Academy Online 支持平板/桌面。
- **自由沙盒**：无。问题优先，不是教具优先（Beast Academy 在线有交互谜题/游戏，但没有开放画布）。
- **错误可视化——Alcumus 的两次机会 + 读解答循环**：每题最多**两次机会**；答对、第二次答错或"放弃"后都能看到完整解答——官方指南坚持**答对了也要读解答**，因为可能有更好的方法。错答还会喂给自适应引擎，而不只是扣分。
- **分步评分——最接近的是通过/精通进度条**：每个主题有进度条：绿色 = "通过"（已证明足够理解）、蓝色 = "精通"（超出要求）。难度实时自适应，目标约 70% 正确率；引擎混合易题/难题，并注入**已通过主题的复习题——答错一道就能让一个主题"反通过"**。这是带牙齿的间隔复习。XP、等级、任务（"连对 5 题"）、成就是装饰性的（明确"对进阶没有影响"）。
- **练习 vs 考试模式**：无考试模式。最接近的是 Alcumus（自适应练习，挑战题无限次尝试）vs MATHCOUNTS Trainer（免费自适应竞赛准备）和限时竞赛练习；Beast Academy Online 有内置章节测试。
- **教师/家长端——Beast Academy 家长仪表盘是五家里对家长最友好的**：家长账号：详细可打印进度报告、每周邮件摘要、**孩子在某个概念上挣扎时报警**。AoPS 在线课有作业标签（Alcumus 主题 + 挑战题），教师给反馈；Alcumus 进度条学生/家长都可见。没有 GeoGebra/Desmos 式的直播课堂仪表盘。
- **探究作业**：整个教学法就是探究：教材先出题、后教方法（"先问题后讲解"）；作业是远超直接应用的挑战题，无限次尝试。Beast Academy 漫画指南里有"停车标志"，让家长先讨论再继续。
- **证据**：中等，五家里最强。(1) NBER 工作论文（2026 年 4 月，泰米尔纳德邦数学人才项目）：AoPS 预代数课 + Alcumus 测验，自适应难度目标约 70% 正确；参与度数据显示游戏化自适应系统让学生坚持下来；最投入的学生从"通过"推到了"精通"。(2) 几十年竞赛成绩：AoPS 是 AMC/AIME/USAMO/IMO 选手的实际训练通道——强选拔 + 结果证据，但不是平台本身的对照因果研究。(3) 用户口碑：天赋/进阶学习者的首选推荐；主要批评是太难（不适合挣扎的学习者）、自学模式无真人教师、直播课贵。诚实标注：没有找到把 Alcumus 与对照课程隔离比较的 RCT。
- **价格**：Alcumus + 视频 + 社区**免费**。Beast Academy Online $15.99/月 或 $99.99/年（兄弟姐妹 $64.99/年，最多 6 孩）；教材约 $25–85/本；直播课另收费（每门几百美元）。
- **来源**：https://artofproblemsolving.com · https://artofproblemsolving.com/school/handbook/current/alcumus · https://beastacademy.com/faq/online

## 2. 国际自适应 / 课程平台

### 2.1 ST Math（MIND Education）——无字错误动画

- **是什么**：视觉空间解谜程序，PreK–8（K–3 最强），网页 + iOS/Android/平板；主要是学校/学区采购（约 $15–30/学生/年），无免费个人层。
- **自由沙盒**：没有开放沙盒——每个活动都是封闭谜题，目标永远是"让企鹅 JiJi 过屏幕"。最接近自由玩的是 JiJi Cycle（分数）：沿数轴滚动分数楔块，把篮子放在你认为总和落点的位置；Push Box：堆方块够到平台高度，加减法变成堆叠 vs 挖洞。
- **错误可视化（招牌）**：**没有文字，没有红叉。错了就把错误动画演出来**：Equal Groups 里小船 visibly 排成对称队形（或排不成），孩子看到"为什么不相等"；JiJi Cycle 里分数滚错了距离。教师可以暂停/倒带/慢放反馈动画。
- **分步评分**：无。**练习/考试模式**：无——一条精通路径，不能跳关、不能猜过去。
- **教师/家长端**：教师仪表盘：实时挣扎报警（彩色方块标记卡住的学生）、分钟数/谜题数指标、"Puzzle Talks"（投影谜题，Think-Pair-Share，讨论动画反馈）。有家长家庭指南。
- **证据**：本组第二强（仅次于 Zearn/DreamBox）。WestEd 跨州准实验（3–5 年级，239 所学校，14 个州）：坚持实施的学校州排名上升约 14 个百分点；SRI 评为 ESSA Tier 2（中等），效应量 0.13（量表分）/ 0.17（达标率）。另有 IES 资助的 RCT（16,307 名学生，52 所学校，3–5 年级），有显著增益，4–5 年级最强。注意：效果高度依赖实施保真度（≥85% 学生、4 月中旬前完成 ≥40% 内容）。
- **来源**：https://2024.mindresearch.org/play · 视频：https://www.youtube.com/watch?v=ywL46ZEnNTs

### 2.2 Zearn Math——CPA + Boost + 100% 通关

- **是什么**：完整 K–8 课程（基于 Eureka Math/EngageNY），网页（桌面/平板）；**家庭和个人教师永久免费**；学校/学区付费（约 $2,500/校高级版）。据称 1/4 美国小学生使用。
- **自由沙盒**：明确的 CPA 进阶。互动视频课用可拖拽的数棒、条形图、位值表；孩子先摆弄模型再答题。没有开放自由沙盒——教具都在引导课里。
- **错误可视化——Boost**：每课结尾的 **Tower of Power** 精通测验（必须**全对**才能解锁下一课），答错触发 **Boost**：把问题拆成更小的步骤、用更强的教具支撑，再重试一道新题。反复挣扎会实时触发教师端的 **Tower Alerts Report**。
- **分步评分**：没有数字分步分；Boost 本身就是步骤拆解，精通是二元的（全对才过）。
- **练习 vs 考试模式**：Tower of Power 就是考试关卡；流利度活动 + 引导练习是练习模式。还有任务级评估。无单独限时考试模式。
- **教师/家长端**：实时教师仪表盘、Tower Alerts、带评分标准的单元评估；每课有纸笔题用于作业/探究式作业；家长账号免费。
- **证据**：**ESSA Tier 1（强）**——本组最高评级。基于大型 RCT（3–5 年级），对数学成绩有因果影响。
- **用户口碑**：普遍称赞严谨且免费；主要抱怨：视频多、Tower of Power 100% 全对关卡让焦虑/低龄孩子受挫、没有游戏世界拉孩子回来。
- **来源**：https://help.zearn.org/hc/en-us/articles/236239188-Independent-practice-Tower-of-Power

### 2.3 DreamBox Math（Discovery Education）——策略感知自适应

- **是什么**：自适应 K–8，网页（电脑/Chromebook）+ 仅 iPad App——**不上手机和安卓平板**。家庭 $12.95/月个人 / $19.95/月家庭（最多 4 孩），年付 $99.95/$149.95，14 天免费试用；学校约 $20–30/学生/年。
- **自由沙盒**：虚拟教具就是课程：数轴、十格阵、分数模型搭建器、方程搭建器、拖拽分组。如分数课先让孩子在数轴上用可拖拽的块搭建分数，符号最后才出现；长除法先从教具 partial quotients 开始，标准算法在后。明确的教学法是"先探索、后讲解"。
- **错误可视化**：即时脚手架——课程根据孩子用的**策略**（不只是对错）调整提示、教具支持、顺序和节奏。用低效策略答对的孩子，和用高效策略答对的孩子，得到的后续完全不同。
- **分步评分**：本组最接近真正的分步评分："智能自适应学习"引擎追踪每次交互——策略、教具使用、错误模式、决策顺序——实时自适应。但**没有给孩子看得到的分步分数**。
- **练习/考试模式**：无考试模式。**Launchpad** 是分班/评估，用同样的教具，"学生甚至不知道自己在被评估"。
- **教师/家长端**：家庭仪表盘 + 教师仪表盘（含熟练度预测，自称每月预测准确率 85% 无需测试）、学生卡住时可把课程截图发给老师；免费教师工具（Quick Images 教具）用于全班数学讨论。
- **证据**：**ESSA Tier 1（强）**——两个 RCT，n=13,320，平均效应 +0.10 SD，K–2 最强。哈佛 CEPR 研究：每周 20 分钟 +2.5 NWEA MAP 分（60 分钟/周约 +7.5）。WWC 评为"可能积极"。注意：厂商汇总会夸大（"多 60% 成长"），独立效应是小到中等。
- **来源**：https://dreamboxlearning.zendesk.com/hc/en-us/articles/27281843188243-How-Does-DreamBox-Math-Work

### 2.4 IXL Math——SmartScore（学它，别照抄）

- **是什么**：自适应**练习**平台（不是课程），PreK–12 数学（另有英语/科学/社科/西班牙语），网页 + App。家庭 $9.95/月 或 $79/年（单科）；$19.95/月 / $159/年（4 科核心）；每多一个孩子 +$4/月；每天 10 道免费题，无免费试用。
- **自由沙盒**：基本没有——问答训练 + 部分可视化题目；这是它公认的短板（没有动手教具、没有 CPA 沙盒）。
- **错误可视化**：即时反馈 + 每次出错后给分步 worked 讲解。最值得研究的机制是 **SmartScore（0–100）**：答对涨、答错跌，80–90 分以上进入"挑战区"后答错扣 3–8 分、答对只加 1–2 分——满分 100 需要持续连对。有人觉得激励，有人觉得惩罚/挫败。
- **分步评分**：SmartScore 是按**题**不是按步；但它是本组最清晰可见的评分模型，其不对称设计值得研究（其反弹也值得注意）。
- **练习/考试模式**：无考试模式；**实时诊断**按技能 strand 给孩子定级并生成个人行动计划——最接近评估模式。技能组织成约 4,900 个离散数学技能（仅 3 年级 413 个），每个都可单独定位。
- **教师/家长端**：本组最强的报告：按 strand 的标准掌握度、班级缺口、诊断行动计划；1300+ 视频教程。
- **证据**：**ESSA Tier 1（强）**，基于一个 RCT：约翰霍普金斯 CRRE，Holland 公立学校，545 名 3–5 年级学生，2023 年春季——比对照组 Renaissance Star Math +10 分，效应 0.13 SD；西班牙裔/英语学习者/贫困生亚组更大（13–17 分）。注意：单一小学区、总共只用 7–10 小时；州考（M-STEP）上无显著效应（0.03 SD）。
- **用户口碑**：最适合针对性补缺和重复；被批评为"练习引擎，不是教学"——不懂"为什么"的孩子仍需别处教。
- **来源**：https://eric.ed.gov/?id=ED641940

### 2.5 Khan Academy + Khan Academy Kids

- **是什么**：Khan Academy——免费非营利，PreK–大学，网页 + App；数学 K–12 + 科学/人文/备考。Khanmigo AI 导师是付费附加（家庭 $4/月；44+ 国家教师免费）。Khan Academy Kids——独立免费 App，2–8 岁（PreK–2 年级），iOS/Android，无广告/内购，5000+ 活动，2100 万+ 用户。
- **自由沙盒**：弱——视频优先（数字黑板上的短课视频）+ 练习；有交互题（如数轴、作图），但没有自由沙盒或教具优先的课程设计。
- **错误可视化**：按需提示 + 链回相关视频；Khanmigo（付费）给苏格拉底式分步引导，不给答案。没有动画错误可视化。
- **分步评分**：无。精通系统：技能从未开始 → 已尝试 → 熟悉 → 精通 → 掌握；能量点/徽章。
- **练习 vs 考试模式——本组最清晰**：练习题 vs 单元测试、课程挑战、精通挑战（间隔、混合主题、考试式关卡）。这是练习/考试分法的抄作业对象。
- **教师/家长端**：教师仪表盘：发代码建班、按标准追踪精通度、进度报告；家长/教练报告。评测说日常练习管理的报告比 IXL"薄"。
- **Khan Kids 机制**：故事引导路径 + 五个角色（Kodi 熊旁白；Peck 蜂鸟管数数；Sandy 野狗管谜题/记忆）；图书馆按书/视频/创作/字母/阅读/数学/逻辑分；自适应个性化路径；教师账号免费，可布置课程 + 班级报告。无分步评分；反馈是角色鼓励下的温和重试。
- **证据**：Khan Academy——免费产品里异常地强：4 个独立 RCT。Hamilton County TN（约 6,900 名中学生，2 年）：+0.06 SD/年，第 2 年 0.08；Arlington TX 3–6 年级：+0.12 SD；萨尔瓦多：+0.09–0.11 SD；印度 RCT（有辅导员保护练习时间）：+0.44–0.47 SD；2026 年 PNAS 研究（20 万+ 学生）：每个技能带到精通约 0.0031 SD。效果高度依赖使用量和教师支持；一个巴西 RCT 因网络/设备故障无效果。**Khan Academy Kids：没有专门的疗效 RCT——证据弱/缺失**（奖项：Common Sense Media 5 星、编辑选择；无学习增益研究）。
- **来源**：https://blog.khanacademy.org/multiple-studies-show-khan-academy-drives-learning-gains-evidence-for-our-platforms-effectiveness/

### 2.6 Matific——游戏化自适应（证据是小样本标题）

- **是什么**：游戏化自适应数学，4–15 岁，K–9 年级，网页 + iOS/Android。家庭约 C$79/年 或 C$11.99/月（地区价不同；美国约 $9.99/月 或 $79.99/年），7 天免费试用；教师免费（30 天试用）；学校许可。690 万安装（AppBrain），Google Play 3.4★（2.4 万评价）vs App Store 4.7★（5.1 万评价）——口碑两极，Google Play 上计费/退订投诉突出。
- **自由沙盒**：冒险岛世界；每个活动（"episode"）是围绕一个想法做的动手谜题——如 Swipe the Ring（早期代数）、Angle Robotics（角的加减）、Bake It!（分数）、Hundred Board、Selling Toys（钱/位值）。教具嵌在游戏里（拖、划、搭建），有操作动画和给不识字孩子的语音提示。没有开放自由沙盒——episode 是布置/引导的，不过孩子可以探索岛屿、重玩喜欢的（Matific 公布的最常重玩榜：Hundred Board、Pyramid Addition、Ramanujan's Game）。
- **错误可视化**：实时提示和线索；2026 年教师培训视频说 AI 帮助"把错误当学习机会，而不是失败"。没有 ST Math 或 Zearn Boost 那种分步错误可视化的公开细节。
- **分步评分**：无——按 episode 完成/星级；教师仪表盘显示每个活动的完成图。
- **练习/考试模式**：无——一条自适应路径；中文站提到有针对性练技能的"训练区"。
- **教师/家长端**：强：教师仪表盘（直播课堂报告、缺口识别、按年级/课程/领域布置、每个 episode 附教案、全班演示模式）、家长仪表盘 + 家长 AI（问孩子进度）、每周汇总邮件。还有可打印的工作表/应用题。
- **证据**：厂商称 6 大洲 25+ 同行评审研究、"每周 30 分钟 +34% 测试分"。锚定研究是真实的但很小：Attard，西悉尼大学——8 所澳大利亚小学，前后测，+34% 可得分。2026 年 PRISMA 系统综述（EMTEKA 期刊）发现动机/参与度持续积极，学习成果增益随实施质量而异——"效果取决于教学整合、教师准备和基础设施，不只取决于平台"。无 ESSA Tier 1/2 评级，无大型 RCT。把"34%"当小样本标题看，不是可推广效应。
- **来源**：https://www.matific.com/mt/en-gb/home/why-matific/research-and-efficacy/

### 2.7 Mangahigh ⚠️ 已永久关闭（2025 年 12 月 31 日）

- **是什么**：游戏化数学，K–10 年级（约 7–16 岁），仅网页。600+ 游戏 + 自适应测验；学校订阅（约 $4.50/用户/月），免费试用。
- **状态——关键**：官网首页写明：*"经过慎重考虑……我们决定永久关闭 Mangahigh/Blue Duck Education。最后运营日为 2025 年 12 月 31 日。"* 来源：https://www.mangahigh.com/en-gb/ 。**不再是可对标或可授权的在售产品**——机制只能从文档/评测里学。
- **核心机制（只借机制）**：
- 游戏就是教具：如 Tangled Web——用角的性质给蜘蛛建一条安全路、躲开带电齿轮（教师用作前测）；Pyramid Panic、Bidmas Blaster。每个游戏自适应难度，让孩子待在最近发展区；连对 3 题升难度，错了降难度。
- **错题 → 分步解析（本组错误分析最佳）**：**Prodigi** 自适应测验（10 题，4 个自适应级别：简单/中等脚手架 → 困难年级水平 → 极端拓展），学生**可以分析错误、在重玩前看到分步展开的解答**——教师快速入门指南里明确写了。表现分段自动路由后续：<50% → 讲解视频，50–80% → 脚手架练习，>80% → 拓展。
- **分步评分**：铜/银/金牌（铜 = 基本理解 + 标准应用；银/金 = 稳固/出色 + 非常规/拓展应用）——三级精通奖牌，不是按步计分。
- **练习 vs 考试模式**：Prodigi 挑战（约 5 分钟，形成性评估/流利度）vs 游戏挑战（约 10 分钟，从头到尾自由玩）——Khan 之后最接近练习/考试分法的。
- **教师/家长端**：Common Sense Education 评为"杀手级教师仪表盘"：给个人/班级/小组布置挑战、实时分析 + AI 分化建议、成绩册、显示哪道题最让人困惑的报告、校际竞赛、课堂模式。无家长入口。
- **证据**：弱/缺失。无 RCT 或 ESSA 评级。证据是教师证言和案例报告。
- **注意**："AIGYM"——任何来源里都没有找到 Mangahigh 叫"AIGYM"的产品；它的自适应引擎叫 **Prodigi**。不要把 AIGYM 当成真实机制。

### 2.8 Prodigy Math——参与度最高，教学最弱

- **是什么**：奇幻 RPG 数学游戏，1–8 年级（6–14 岁），网页 + App。**所有数学内容免费**；Premium（$9.95/月 Level Up，$14.95/月 Ultimate；约 $75–100/年）只买装饰、宠物、更快进阶——不锁数学。英语是单独订阅。声称 1 亿+ 用户；约 80 万教师/年。
- **自由沙盒**：游戏世界本身就是参与层：巫师角色、任务、怪兽战斗、宠物收集。数学题界面有提示气泡、视频课、文字转语音和**数字教具**（如屏幕上的十进制方块）——但教具是题内的帮手，不是自由沙盒。
- **错误可视化**：答错 = 法术落空/战斗动作失败——低风险、无惩罚；题目提供嵌入式诊断提示和可视化辅助，自适应算法降低难度。没有"为什么错了"的动画可视化。
- **分步评分**：无。**练习/考试模式**：无考试模式；教师可设目标（如每周 50 道标准对齐题）并布置特定技能；有备考题集，其游戏内表现可预测州考成绩。
- **教师/家长端**：免费教师仪表盘 + 报告；家长仪表盘（付费层增强追踪）。教师可创建题目/作业，通过自适应算法投放。
- **证据**：弱——只有相关性，且有争议。约翰霍普金斯 CRRE 混合方法评估（2020 年 1 月，约 450 名 4 年级学生，一个美国南部学区）：用得多与州考分高相关，但约 888 道题才换 1 分；家庭使用不显著；高用量组与中用量组无差异。同一报告指出"缺乏补救和实际教学"、"分散数学注意力的东西来自游戏内部"（换装、布置房子、闲逛）。2021 年 FTC 投诉（Campaign for a Commercial-Free Childhood）指控其疗效营销有误导性、Premium 造成数学成就的虚假印象。Knox County 的 RCT 已注册但未找到结果。
- **用户口碑**：独立测试里自愿参与度最高（一个不情愿的 10 岁孩子 14 天里主动玩了 14 天），但每分钟数学量最低（20 分钟里约 6 分钟在做题），儿童视图里频繁出现内购推销。
- **来源**：https://jscholarship.library.jhu.edu/server/api/core/bitstreams/c38fbad0-2746-4c00-8654-5d0854d2a99c/content

### 2.9 Mathletics（3P Learning）——练熟 + 直播竞赛

- **是什么**：在线数学补充，5–16 岁（K–12 年级），网页 + 平板 App。家庭约 $99/年/学生（常打折 $59）；学校许可便宜得多。NAPLAN 研究里 1000+ 澳大利亚学校使用。
- **自由沙盒**：弱——主要是自适应活动（1200+）加可视化支持，另有 Rainforest Maths（自选级别）、Times Tables Toons（歌曲/视频）、解题和概念搜索区。没有自由沙盒或教具优先设计。
- **错误可视化**：即时反馈；活动按主题分易/核心/难三档；可重试。没有错误可视化或分步解析系统的文档。
- **分步评分**：积分制：金条、证书（按周积分的铜/银/金周证书）、**Live Mathletics**——与同学/世界/电脑进行的实时 60 秒流利度竞赛，有级别和双倍积分奖励关卡。积分是激励，不是诊断。
- **练习/考试模式**：无考试模式；教师/家长可设任务/作业，做完才能解锁挑战。
- **教师/家长端**：教师中心 + 管理中心（课程创建器、任务管理器、班级成绩册）；家长中心（可打印练习册/电子书、题型指南、每周邮件进度报告）；家长每年最多可调 6 次级别。
- **证据**：中等。LearnPlatform（Instructure）准实验研究，2022–23 年，1,885 名 3–5 年级学生，8 所学校：使用者 NWEA MAP 高于非使用者，效应 0.11 SD（约 50 → 54 百分位）；**ESSA Tier II（中等）**。3P 委托的 NAPLAN 分析（2025 年 8 月，1000+ 学校）发现 3 年级 +7.6、5 年级 +9.6 分，但它是相关性研究且由厂商委托（报告里 Cohen's d 4.52/5.98 大得不合常理——很可能是标错了，持怀疑态度）。
- **来源**：https://marketing-cdn.3plearning.com/uploads/assets/mathletics/mathletics-efficacy-study-august-2024.pdf

### 2.10 SplashLearn——家长可见性强，游戏化过重

- **是什么**：游戏化自适应数学（PreK–5 年级）+ 阅读（PreK–2 年级），约 3–11 岁，网页 + App。教师/学校免费；家庭订阅约 $7.49–11.99/月（$69.99–95.88/年），家庭计划最多 3 孩；有限免费层。声称 4000 万+ 学生。
- **自由沙盒**：两个世界（数学世界、阅读世界）+ 个性化学习路径；游戏伪装训练（如水下/太空主题数字游戏）。按正确率 + 反应时间自适应难度。另有一个"游戏区 / Secret of Numeras"自由玩区域，但**明确排除在进度报告之外**——即自由玩被刻意与学习测量脱钩。没有开放式教具沙盒。
- **错误可视化**：即时反馈 + 难度调整；无错误可视化或分步解析的文档。
- **分步评分**：无——按技能/标准追踪精通度。
- **练习/考试模式**：无；教师可布置课堂作业和家庭作业，路径本身就是练习。可选按需 1 对 1 辅导附加（约 $20/节）补概念缺口。
- **教师/家长端**：在其年龄段里很强：教师仪表盘（每个学生进度和缺口识别、布置课堂/家庭作业）；家长仪表盘 + 独立的 Parent Connect App（显示已掌握技能、连胜、问题区）；报告可按孩子/年级/科目筛选。
- **证据**：弱到中等。ESSA Level III（有前景），2025 年凭一项相关性研究获得（2023–24 年，一个北卡学区，K–5 年级）：每周解题越多 → 最终精通度越高，K–4 尤其明显；解题频率比用时长更能预测结果。ESSA Level IV（有依据）2024 年。无 RCT；厂商的其他数字（如"2 个月学习提升 77%"、"92% 教师看到新技能"）是不受控的营销说法——忽略。
- **用户口碑**：家长可见性和 K–5 适配受称赞；被批评游戏化重到分散学习注意力，5 年级就到头了。
- **来源**：https://www.splashlearn.com/blog/splashlearn-achieves-essa-level-three-certification/

### 2.11 Moose Math（Duck Duck Moose / Khan Academy）——RCT 证明没有优势

- **是什么**：低龄数学冒险，3–7 岁（幼儿园–1 年级 Common Core），仅 iOS/Android App。**完全免费，无广告，无内购**（Khan Academy 收购的子公司；实际已被 Khan Academy Kids 取代，覆盖同一低龄段且更广——Moose Math 商店列表显示最后更新 2025 年 10 月/2026 年，但无新功能开发的证据）。
- **自由沙盒**：小镇里五个多级别活动：Moose Juice（做冰沙——用水果块做计数器练计数/加减）、Paint Pet（按点数配对宠物）、Pet Bingo（解题得宾果）、Lost & Found（按形状/颜色分类）、Dot to Dot（数字模式）。奖励用来建设/装饰孩子的城市——建城是最接近自由沙盒的东西，但它是奖励装饰，不是数学探索。
- **错误可视化**：角色帮助下温和重试；按正确率自适应难度。无错误可视化或讲解。
- **分步评分 / 练习/考试模式**：均无。
- **教师/家长端**：Report Card 区，供家长/教师监控进度、找更多练技能的活动——基础，无仪表盘。
- **证据**：弱——**唯一找到的严谨研究显示没有优势**。Herodotou et al.（2022，RCT，376 名 5–6 岁儿童，3 所英国学校）：Moose Math 的学习增益**等于标准数学练习，不优于它**；被归类为"训练-练习/指导式"App，认知 effort 有限。无 ESSA 评级。用户口碑温和（家长喜欢温和、无广告的设计；10–15 分钟一节），但它是个流利度玩具，不是教学工具。
- **来源**：https://online-journals.org/index.php/i-jim/article/download/27893/11091/94647

## 3. 解题与游戏类

### 3.1 Photomath（Google，2014 年创立，2023 年被 Google 收购）

- **是什么**：拍照优先的移动端解题器。小学算术 → 微积分，约 1–12 年级 + 大学。仅 iOS/Android App——**无网页/桌面版**；需要联网（照片上传云端）。免费增值：Basic 免费（拍照扫描 + 智能计算器 + 机器生成的分步解答）；Plus $9.99/月 或 $69.99/年，增加动画教程（400+）、教材解答、自定义可视化辅助、更深的"怎么/为什么"提示。
- **核心机制**：相机对准印刷/手写题（如 `2x + 6 = 14`），OCR 识别，可编辑识别出的表达式，然后返回完整解答（每步可展开）；部分题有多种方法 + 交互图像。
- **错误流程**：基本**没有错题流程**——Photomath 是替你解题，不是让你先解。最接近的是 Plus 的情境提示和动画白板教程（模拟老师讲解）。
- **分步评分 / 练习/考试模式 / 教师/家长端**：均无。
- **证据**：弱。无大型 RCT。小样本、低质量研究：印尼边境学校一项前后测研究（单组设计）报告代数分数 +36.25%、积极性高；2026 年尼日利亚本科生研究（n=183）发现 Photomath 教的学生微积分优于传统教学，与 Mathway 无显著差异；2024 年印尼八年级研究（n=23）发现学习兴趣**无显著差异**。都是小样本、准实验、低档期刊——仅供参考。用户层面下载量/流行度很高（a16z 排名前 50 移动应用），但那不是学习证据。
- **来源**：https://hokai.io/hub/tools/photomath

### 3.2 Symbolab（Course Hero）——练习/测验双模式最干净

- **是什么**：网页 + iOS/Android 分步解题器 + 练习工作区。预代数 → 多元微积分、矩阵、几何证明、部分化学数学——主要是 7–12 年级/大学，**对 1–6 年级太难**。免费增值：免费层给最终答案 + 2D 作图，步骤有每日限额；Pro 约 $9.95/月、$32.95/半年、$39.95/年（部分商店标价 $2.49/周–$6.99/月，价格不一致——以官网为准）。
- **核心机制**：输入或拍照（如 ∫x²dx），展示每一步代数变换及理由，另有带滑杆的 2D/3D 交互作图计算器（拖系数看曲线动——直接对应我们的函数滑杆演示）。
- **练习 vs 考试模式——本轮调查里分得最清楚的例子**：**练习模式**把学科按难度排成主题；一次解一题，点"提示"（每个提示揭示一步），输入答案，点"验证"即时对/错；建议每主题答对 5 题再进阶。**测验模式**（每级结尾，约 10 题）：**无提示**，结尾给总分。这就是练习/考试双模式，可直接借。
- **错题**：练习里答错只说不对——重试或再要一个提示；不诊断**哪一步**错了。
- **分步评分**：无——按整题计分（每主题答对题数）。**教师/家长端**：无。AI 聊天（"Symbo"）可问任何一步。笔记本：保存任何已解的题 + 私人笔记、标难度——个人错题本的对应物。
- **证据**：学习效果方面无证据——无 RCT 或疗效研究；证据是用户口碑（2026 年某对比里应用商店 4.1/5）和评测对步骤深度的称赞。标注为**无疗效证据**。
- **来源**：https://ailab.mobi/tool/symbolab/ · http://blog.symbolab.com/2015/07/practice-practice-practice.html

### 3.3 DragonBox（WeWantToKnow AS，挪威；现 Kahoot! 旗下）——游戏教代数

已验证的套装（5 个核心数学游戏 + 后来的 Kahoot 补充）。全部是**一次性付费购买**（2020 年价格：Numbers $7.99、Big Numbers $7.99、Algebra 5+ $4.99、Algebra 12+ $7.99、Elements $4.99；完整包 $24.99）——**现也通过 Kahoot!+ 家庭订阅销售**（2026 年某报价 $5.99/月 或 $35.99/年；价格随时间变，以官网为准）。仅 iOS/Android，无网页版。没有自己的教师仪表盘（课堂使用走 Kahoot!）；无分步评分；无练习/考试模式。

**DragonBox Numbers（4–8 岁）**：数字 1–10 是不同长度/颜色/声音的角色 Noom（活的 Cuisenaire 棒）。四种模式：**Sandbox**（自由玩——堆、切、喂 Noom，没有目标；明确设计成家长/教师可以借此教）、**Puzzles**（250 谜题——拼出合适大小的 Noom 填满俄罗斯方块式空位、揭示一幅画）、**Ladder**（堆 Noom 够星星、躲炸弹）、**Run**（无尽跑酷心算）。具体例子：要拼出 8，可以把 5-Noom 喂给 3-Noom，或把 4 切半得 2+2；游戏从不惩罚"多拼了 Noom"——实验是免费的。

**DragonBox Big Numbers（6–9 岁）**：资源管理游戏学数位：收集苹果、按个/十/百分组、手指写总数、换苹果买金币、解锁 6 个世界。带进位/借位的长加减从经济系统里长出来，不是训练。约 4,000 次运算。

**DragonBox Algebra 5+（5 岁+）和 12+（9 岁+）——本报告里最值得借的游戏**：双托盘棋盘；目标是把发光的盒子（X）单独留在某一边。拖图片卡；加一张卡的"夜晚"（负数）孪生卡会抵消（漩涡）；**你不能只在一边操作而不镜像到另一边——天平规则由游戏物理强制执行，不是讲出来的**。10 章里图片卡逐渐被数字、变量、算符取代，孩子在见到符号之前就学会了解方程的动作。5+：100 谜题；12+：192 谜题 + 164 附加，加入分数、因式分解、代入、括号。

**错题**：非法拖拽根本通不过（卡片弹回/操作被拒绝）；**没有提示**。评分按关卡：最多 3 星——1 星解出、1 星用了正确的步数、1 星用了正确的卡数。那个"效率星"是轻量版分步评分（步数，不是步骤对错）。

**DragonBox Elements（9 岁+）**：用欧几里得证明做几何——拯救欧几里得岛，靠发现图形的性质/定义/关系；证明是当谜题搭出来的，不是写出来的。文档比 Algebra 少；无单独疗效研究。

**证据——本报告里最强的**：2023 年 RCT（Decker-Woodrow et al.，*AERA Open*；N=1,850 名七年级学生，9×30 分钟，教室内随机）：DragonBox 12+ 的代数后测分数**显著高于主动对照组**，What Works Clearinghouse（IES，2026 年 5 月复核）评为"统计显著正效应"/符合 WWC 标准。后续研究（*J. Computer Assisted Learning*，2023，n=887）发现增益主要在**概念性**知识，程序灵活性增益到后测时消退。成本效益分析：约 $55/学生，效应 0.269，每效应单位 $206——比替代品便宜。注意：效应针对七年级代数、短期干预；低龄游戏无证据。
- **来源**：https://www.dragonboxapp.com/about · https://ies.ed.gov/ncee/WWC/Study/91151 · 视频：https://www.youtube.com/embed/hGHDBUkmUIE

### 3.4 Graspable Math + From Here to There!（FH2T）——非法操作做不出来

- **是什么**：网页动态代数画布（graspablemath.com）+ iPad 游戏 FH2T，印第安纳大学研究项目（Ottmar/Landy）。公开测试版免费探索；课堂许可付费。约 6–12 年级。
- **核心机制——本轮调查里最好的错误可视化模型**：表达式是物理对象。把一项拖过 `=` 它就变形；拖进括号就分配；把两项拖到一起就因式分解。**非法操作在物理上不可能：那一项会抖一下弹回来**——规则是"感觉到"的，不是"讲出来"的。错误的**策略**选择（如该减却加了 5）是被允许的，但会 visibly 让表达式更复杂，而且一切可逆（撤销，不用擦/重抄）。每一步都被记录成教师可查的可见步骤历史——这是本轮调查里最接近分步评分 + 教师可见性的东西。FH2T 每道谜题后加一张记分表：**效率、错误数、金星**。
- **证据**：与 DragonBox 同一个 2023 年 RCT（N=1,850）：FH2T 也显著优于主动对照组的代数后测（WWC：统计显著正效应）；FH2T $39/学生，效应 0.135。概念知识强于程序知识（同一后续研究）。
- **来源**：https://graspablemath.com/ · https://activities.graspablemath.com/branch/d/explorations/

### 3.5 ASSISTments——教师/家长 + 探究作业的最佳模型

- **是什么**：免费（Plus $8/学生/年起）网页作业平台，K–12 年级，基于 Illustrative Mathematics 课程。**不是游戏——是作业系统。**
- **核心机制**：教师布置题组；学生做题时得到**即时反馈 + 每题提示/脚手架**（作业被重构为"学习机会"）；错题可重试加提示。教师得到实时**作业报告：按题的错误分析**——全班哪道题错了、常见误解、谁需要帮助——加上班级/学生进度报告和 AI 汇总的误解。这是"教师看到错的步骤，而不只是错的分数"的模型。
- **证据——本轮调查里最强**：**最高级**评级（Evidence for ESSA / evidencebasedprograms.org）；两个大型 RCT（缅因州：46 所学校，3,050 名七年级学生；北卡：63 所学校，9,073 名学生），标准化测试上有可观效应（第 2 年约 0.18 SD；缅因效应约等于一年预期增益的 60%）。注意 2023 年的 RCT 发现**单是即时反馈题组**并没有优于主动对照组——效应似乎来自教师反馈闭环，不只是反馈本身。
- **来源**：https://www.assistments.org/assistments-plus · http://evidencebasedprograms.org/programs/assistments/

### 3.6 其他（本轮已验证，简述）

- **DreamBox / Zearn / Prodigy**：机制见第 2 节；本轮补充：DreamBox 引擎自称每小时捕获约 48,000 个数据点（每次点击、按键、对错、用时），实时调难度/顺序/提示数/节奏；错题被当作信息而非失败，系统给即时脚手架并改道课程；教师仪表盘有使用/进度/成长报告、课程推荐和分组建议；家长有"家庭洞察仪表盘"。Prodigy 答错只显示正确答案、不解释为什么——评测一致认为它**不解释错误**；家长/教师仪表盘显示已掌握 vs 卡住的技能、可打印工作表、目标设定。Zearn 的 Boost 和 Tower Alert 见 2.2。
- **Microsoft Math Solver**：**2025 年 7 月停用，已从应用商店下架**（不要抄、不要引用）。Mathway 存在，但在 Symbolab/Photomath 之外没有独特之处（解题器 + 付费步骤），不展开。

## 4. 中国数学 App

### 4.0 总览（诚实版）

**没有任何一家有真正的 NB实验室式套装**：没有开放式教具的自由沙盒、没有分步评分、没有练习/考试双模式、没有探究作业。最接近的只是零散的单个功能（见 4.11）。多数 App 分三类：(1) 动画视频 + 测验（洋葱、天天练）；(2) 真人小班直播（火花、豌豆、猿辅导、作业帮/有道精品课）；(3) 2–8 岁 AI 录播课 + 点触互动（斑马、洪恩、悟空、都都、小猴、瓜瓜龙）。**证据质量普遍弱**：没有同行评审的 RCT 或对照研究；证据是家长个案、营销数字（用户量、"1.1 亿学生"）、应用商店文案。

### 4.1 洋葱学园（原洋葱数学）——教师端最强

- **是什么**：小初高全科动画课；数学是起点学科。5–8 分钟动画微课，8000+ 节，覆盖 50+ 教材版本。App（iOS/Android/iPad）+ 网页 + 学习机；另有教师版、合作校版。
- **年龄/年级**：小学–高中（数学全学段）；小学数学同步课是主打。
- **价格**：免费下载，部分基础课/题库免费；付费按学科/年：小学数学同步课约 ¥498/年，思维培优 ¥498/年，总复习 ¥698；三科合计约 ¥5,100/年；小学–初中六年综合包 ¥5,898（据 2026 年《财中社》/东方财富报道的规划师报价）。
- **核心机制**：
- 动画即教具：概念讲成 5–8 分钟故事动画（如函数讲成投篮抛物线、几何讲成积木搭建）——可视化本身就是讲解，但孩子是**看**而不是**摆弄**。互动是视频后嵌入的点选 A/B 题，再给讲解。
- **错题本三态**：错题自动进错题本，分三类——未改错 / 顽固错题（反复错的，显示做错次数）/ 已改错；学生可自贴错因标签后重做；支持筛选后下载打印。
- 分步评分：**无**，按题对错计分。
- 练习/考试：**无明确双模式**。"智能练习"每微课后推 5–8 道递进题；另有刷题/真题测试入口和 500 万+ 题库，但无模拟考试。
- **教师/家长端——本次中国调查里最强**：洋葱学园教师版（App Store，免费）：分层练习布置、学生做题实时统计、学情掌握、选题本、试卷库（近三年各地真题）、备课教研室；合作校版学生端接收老师布置的预习/同步练习/查漏补缺/考试真题任务；家长可通过微信服务中心查看学情报告。
- AI 导师（2025–26）：拍照上传题目后 AI 不直接给答案，而是匹配动画片段 + 生成"导学提纲 + 打包课程"；AI 规划导师按年级/教材/当前分数段/目标自动排课；AI 自律伙伴每天推送个性化任务。
- **证据**：1.1 亿学生用户、336 万教师使用（公司口径，未经独立验证）；家长个案（如"半年数学 70→90 分"）来自营销软文，无对照研究。错题本三分类是真实产品功能（多篇使用指南证实）。
- **来源**：https://yangcongxueyuan.com/ · https://apps.apple.com/ph/app/洋葱学园-原洋葱数学小初高数学、物理多学科在线学习平台/id990959871

### 4.2 火花思维——"小老师讲题"最接近讲回

- **是什么**：3–12 岁数理思维真人小班直播课（K1–K3 启蒙 + P1–P6 小学，九阶；2026 年升级为"火花新思维"，同一年级 8 种难度班型，动态升降）。
- **平台**：App（学生端 + 家长端），iPad/手机/电脑；配套实体学具盒邮寄到家。
- **价格**：约 ¥80–100/节；课包如 30 课时 ¥3,780、60 课时 ¥6,280（约 ¥78–95/节）；另有 AI 录播版"小火花思维"约 ¥1,300–1,798/级别。
- **核心机制**：
- 教具：自研游戏化互动课件 + 实体学具（如用实物摸"数位/图形/空间"）；课堂结构是独创"六步教学法"：好奇—探索—猜想—验证—反思—应用。
- 错题：老师当堂追问思路（"你是怎样考虑的？""这样会不会更好？"），在 4–8 人小班里实时纠正思路偏差；课后老师对错题发语音+图片请孩子再思考一遍。不是系统自动诊断，是真人对话式纠错。
- 分步评分 / 考试模式 / 沙盒：**均无**。
- 教师/家长端：家长端 App：私人定制学习规划、督学伴学、学习报告、家长社区；课堂"2 分钟 1 次与老师 1 对 1 互动"（官方口径）；6 名老师对 1 名学生服务（班主任+授课老师 2 对 1 私教群，官方口径）。

### 5.2 Oppia——按具体错答分支反馈（最值得学的机制模型）

- **仓库**：https://github.com/oppia/oppia · **Stars**：6,977 · **许可证**：Apache-2.0 · **最后提交**：2026 年 11 月 5 日 · 17,039 提交，108 个 release——维护非常活跃。

- **核心机制**：
- **按错答分支的反馈（误解驱动）**：答错不只说"错了"——课程按*你答错的是哪个答案*分到不同的讲解。如答 `1/2 + 1/3 = 2/5` 会被带到一张"你把分子分母分别相加了"的补救卡。

- **技能精通 + 复习测试**：每 3 章后出现一次复习测试；结果更新每个技能的精通等级，驱动接下来练什么。
- **丰富的数学输入类型**：分数输入、作图输入、代数表达式输入、比值输入、数值表达式输入（不只是选择题）。
- **成熟度**：生产级、Google 出身的非营利、GSoC 规模社区。代码库太大，没法整个搬，但反馈分支和未处理答案的想法可以直接搬进我们自己的内容模型。

### 5.4 GeoGebra（开源镜像）——学绑定模式，别嵌代码

### 5.6 Anki——间隔重复的金标准（用算法，别抄代码）

- **仓库**：https://github.com/ankitects/anki · **Stars**：32,606 · **许可证**：AGPL-3.0 · **最后提交**：2026 年 11 月 5 日 · 12,622 提交，89 个 release——非常活跃。

- **核心机制**：**四级自评驱动排期**：每张卡后 Again / Hard / Good / Easy——评分本身就是排期输入，这正是我们的自评 + 信心想法，只不过形式化了。**FSRS（Free Spaced Repetition Scheduler）**：用 21 个参数建模每张卡的难度、稳定性、可提取性，预测最优下次间隔，而不是固定的 1/3/7 天档。**详细统计 + leech 检测**：失败太多次的卡自动标为"leech"拿去返工——我们错题本的好模型（老是失败的题标出来换种表征重做）。

### 5.7 Álgebra 3D——3D 代数方块（想法可借，代码别抄）

## 7. 可借鉴清单（按优先级排名，映射到我们的 App）

我们的 App 现状（对比基准）：1–9 年级数学，142 个知识点；CPA 可视化；4 个互动演示（分数饼图 + 数轴、十格阵凑十/破十、天平解方程、函数滑杆）；数学实验室自由沙盒；每知识点有先考题、怎么做、为什么、易错点、看图学、动手试一试、讲回来、练一练（基础 → 提高 → 奥数挑战）；间隔复习（今天复习）、混着练（交叉练习）、自评 + 信心校准；完全免费、无登录、平板 + 桌面端。

**第 1 位：分步评分 + 丢分定位——全网空白点，第一个做出来就是差异化**

- 来源机制：NB实验室的模拟测按步骤给分（首要借鉴点）；Zearn Boost（错了拆成小步重做再重试新题）；Mangahigh Prodigi（错后看分步展开解答再重玩，按 <50% / 50–80% / >80% 分段路由后续）；DreamBox（按策略而非对错自适应，但不给孩子看分数）；Oppia（按具体错答分支反馈）。
- 我们现状：**没有**。现有自评是整题对/错 + 信心；不知道学生卡在哪一步。
- 怎么借：把多步骤题拆开评——解方程题拆成「移项 / 合并 / 系数化 1」三步自评；应用题拆成「列式 / 计算 / 答」三步；几何证明题拆成「已知 / 关键步骤 / 结论」。测完给一张「丢分位置」小报告，并自动把丢分步骤对应的知识点推入今天复习。先从奥数题和提高题试点（步骤天然清晰）。判定答案等价用 mathjs（§5.9）而不是字符串比对；学生输入用 MathLive 的 `<math-field>`（§5.9）才能真正按行检查。
- 预期收益：没有一家数学 App 真正做这个；做出来就是我们的招牌。

**第 2 位：练习模式 vs 考试模式——Symbolab + Khan 的分法直接抄**

- 来源机制：Symbolab Practice（有提示、每个提示揭示一步、建议答对 5 题再进阶）vs Quiz（无提示、约 10 题、结尾总分）；Khan 练习 vs 单元测试/课程挑战/精通挑战（间隔、混合、考试式关卡）；GeoGebra 考试模式（锁机、计时、空白起步、退出截图——抄规则不抄实现）；Zearn Tower of Power（100% 全对才解锁下一课——严格版，可作可选的严格档）。
- 我们现状：**只有练习态**。混着练、今天复习都有提示和自评，没有"无提示、限时、按步骤给分"的考试态。
- 怎么借：新增「模拟测」：每周一套 5 道题（从已学知识点抽），限时、无提示、做完按步骤给分并出丢分报告（接第 1 位）；平时练习保持有提示。注意不要做成高压考试——定位是「检验自己学到哪了」，测完立刻给复习建议。Khan 的分法更温和，Zearn 的 100% 关卡更严格——先做 Khan 版，100% 关卡只放在复习模式里可选开启（Zearn 的 100% 规则被批评让焦虑的孩子受挫）。
- 预期收益：NB 清单第 2 位（与分步评分同属一套）；Symbolab 和 Khan 都证明这个分法是成熟产品形态。

**第 3 位：FSRS 间隔算法升级 + AoPS"反通过"——便宜、立刻见效**

- 来源机制：ts-fsrs（MIT，§5.9）：4 级自评（Again/Hard/Good/Easy）+ 难度/稳定性/可提取性模型；`preview()` 在答题前就展示 4 个等级各自的下次到期日。Anki 的 leech 检测（失败太多次自动标出返工）。AoPS Alcumus：复习题答错能让已通过的主题"反通过"（绿变回未通过）。
- 我们现状：**已有固定 1/3/7 天规则** + 自评 + 信心。规则是手写的，不是个性化记忆模型。
- 怎么借：把今天复习的排期从固定档换成 ts-fsrs（MIT 许可，可直接用；另见并行的 GitHub 开源调研报告 `docs/research/github-math-opensource-20261106/`，其中有 FSRS 的 UMD 构建可直接内联进单文件 HTML 的验证）。同时加 AoPS 的规则：复习题答错，已通过的知识点降级、重新进入复习队列。加 Anki 的 leech 规则：失败 ≥N 次的题标出来，换种表征重做，而不是重复同一道题。
- 预期收益：改动小（排期函数替换 + 两条规则），复习从"固定档"变成"按记忆模型个性化"；AoPS 的"反通过"让复习有后果，不再是走过场。

**第 4 位：错因标签 + 错题三态 + 变式推送——补错题本的短板**

- 来源机制：小猿AI 错因二分法（知识性错误 vs 习惯性错误）+ 错题自动归类 + 举一反三；洋葱错题本三态（未改错 / 顽固错题（显示做错次数）/ 已改错）+ 打印导出；Oppia 按具体错答分支反馈（如 `1/2+1/3=2/5` → "你把分子分母分别相加了"）；洪恩母题 + 变式（185 道母题，每道配子题变式）；学而思学习机"错题回顾 20% + 基础巩固 80%"智能组卷。
- 我们现状：**部分有**。错题本只有对错 + 信心；没有错因、没有状态、没有变式。
- 怎么借：自评"错"之后加一步一键错因（看错数 / 方法错 / 计算错 / 概念错——Brilliant 的"解释为什么错了"的轻量版）；错题按三态管理，顽固错题显示错误次数、天然形成优先级；混着练按 2:8 配比错题变式与新题（而不是纯随机）。Oppia 的"未处理答案"日志也值得抄：把学生没见过的错答记下来，以后给它写反馈。
- 预期收益：错题本从"记录"变成"诊断 + 推送"；全部是现有数据上的呈现层和规则层，成本低。

**第 5 位：教师/家长端 + 探究作业——ASSISTments + 洋葱教师版 + 火花小老师**

- 来源机制：ASSISTments（教师实时看到按题错误分析、共性误解、谁需要帮助；两次大型 RCT，ESSA 最高级）；洋葱教师版（分层练习布置 + 学生做题实时统计 + 选题本 + 试卷库）；小猿AI（教师建班、在线布置练习、自由组卷）；Zearn Tower Alerts（孩子反复卡住时实时报警）；Beast Academy 家长报警（孩子在某个概念上挣扎时通知家长）；火花"小老师"视频（孩子录视频讲思路，80 万+ 学员参与、吉尼斯纪录）。
- 我们现状：**没有**，只有学生端自学。
- 怎么借（分两步）：第一步做轻量家长版：每周学习摘要 + 挣扎报警（一个知识点一周内 3 次错/低信心就提醒）+ 错题按错因汇总（接第 4 位）。第二步做教师版：布置任务（选知识点组卷）+ 实时学情 + 共性错因（接 ASSISTments 的按题错误分析）。探究作业从"小老师讲题"起步：老师布置"用十格阵拼出 8+6 的三种方法"，学生提交操作过程而非只交答案；再往后做真正的开放探究（"在厨房里找 3 个分数，估一估、带回来"）。
- 预期收益：NB 清单里的远期项；ASSISTments 证明教师反馈闭环本身就是效果来源（单是即时反馈题组没有优于对照组）。

**第 6 位：非法操作物理——Graspable Math + DragonBox 的规则感**

- 来源机制：Graspable Math（表达式是实物；非法操作拖过去会抖回来，规则是"感觉到"的；错误的策略选择被允许但会 visibly 让表达式更复杂，一切可逆）；DragonBox Algebra（不能只在一边操作而不镜像到另一边——天平规则由游戏物理强制执行，不是讲出来的；非法拖拽弹回）。
- 我们现状：**部分有**。天平演示放错砝码会倾斜（已有）；但其他演示里非法操作没有"物理拒绝"。
- 怎么借：天平演示里"只在一边加砝码"时让操作抖回 + 提示"两边要做同样的事"；分数/十格阵演示里只有合法的拆分/合并才能通过。DragonBox 证明孩子从"拒绝"本身学会规则，不用讲解。这是错误可视化（在建的第 2 项 NB 借鉴）的下一层。
- 预期收益：改动集中在 4 个演示的交互规则上；DragonBox 和 Graspable Math 各有一个 N=1,850 的 RCT 支撑这类设计。

**第 7 位：提示阶梯 + "先解析后答案"——Brilliant + 有道小P**

- 来源机制：Brilliant 提示阶梯（提示 1 = 往正确推理上推，不给答案；提示 2 = 关键步骤；答错后问"你觉得错在哪一步？"）；有道小P"先解析后答案 + 按学段换解法"（低年级用算术思路、高年级用代数思路讲同一题）；Zearn Boost（错了拆成小步重做）。
- 我们现状：**部分有**。练习是点一下直接看答案；Q1 提示前置、Q2 提示在按钮后（worked-example fading 已有）。
- 怎么借：把"看答案"改成两级提示：提示 1（思路提示，不给答案）→ 提示 2（关键步骤）→ 再看答案。答疑时按学段换解法（低年级算术、高年级代数）。这是第 1 位分步评分的轻量前置：先让学习者自己定位错在哪一步，再谈按步给分。
- 预期收益：成本低；Brilliant 的提示阶梯和有道小P的克制设计都是成熟形态。

**第 8 位：闯关式知识路径 + 奖牌制精通——Mangahigh 奖牌 + DragonBox 星星**

- 来源机制：Mangahigh 铜/银/金牌（铜 = 基本理解 + 标准应用；银/金 = 稳固/出色 + 非常规/拓展应用）——比 0–100 分更适合 1–9 年级的精通隐喻；DragonBox 3 星（解出 + 步数对 + 卡数对）；GCompris 的星星/气球（温和、不惩罚）；Zearn Tower of Power（全对解锁下一课）。
- 我们现状：**有雏形，未显性化**。已有按年级/维度的学习路径和进度统计，但没有"闯关"的感觉；演示进度只是计数。
- 怎么借：每单元设一个"实验任务"（如完成分数演示的 3 个挑战），完成后解锁下一单元并在进度条上点亮；精通按铜/银/金三级（基础题对 = 铜，提高题对 = 银，奥数题对 = 金——正好对应我们已有的三级 ladder）；演示完成后给星级（按步数/错误数，接第 6 位的 FH2T 记分表：效率 + 错误数 + 星星）。先做视觉层（进度点亮 + 完成徽章），不改内容结构。
- 预期收益：低成本；把已有的三级 ladder 变成看得见的奖牌。

**第 9 位：几何/函数演示升级——JSXGraph + GeoGebra 绑定模式**

- 来源机制：JSXGraph（MIT/LGPL，§5.9）：交互几何、函数作图、约 200 kB、无依赖、支持触摸；GeoGebra 的代数 ⟷ 几何双向绑定（输入 `y = 2x + 1` 出现一条线；拖线方程跟着更新）；PhET 的多表征联动（同一个分数同时是饼图、数轴、矩形）；Álgebra 3D 的面积模型因式分解（`x²+5x+6` 拼成 (x+2)(x+3) 矩形）。
- 我们现状：**部分有**。函数演示只有滑杆改方程；没有拖图改方程；没有几何演示；没有因式分解可视化。
- 怎么借：函数演示加"拖直线改方程"（GeoGebra 绑定模式，用 JSXGraph 实现）；新增几何演示（拖顶点看边长/角度/坐标联动）；新增因式分解面积模型演示（7–9 年级）。KaTeX（MIT）顺手把全站分数/方程显示升级成 TeX 质量。
- 预期收益：补齐 G7–9 的可视化短板（7–9 年级内容已有，但演示只有函数滑杆）；JSXGraph 是 MIT 许可，可直接用。

**第 10 位："发现时刻"小故事——NB 报告的第 7 位，成本最低**

- 来源机制：NOBOOK 官网"回到真理诞生的第一现场"、科学彩蛋；Mathigon 的互动教材叙事。
- 我们现状：**没有**。每知识点有"为什么"，但没有"这个知识是怎么被发现的"。
- 怎么借：每单元加一段 2–3 行的发现小故事（如高斯 1+…+100、勾股定理的发现、圆周率的逼近），放在"为什么"后面。成本最低，记忆点最高。

**第 11 位：沙盒分模式——DragonBox Numbers + SplashLearn**

- 来源机制：DragonBox Numbers 的 Sandbox（自由玩）/ Puzzles（拼到目标）/ Ladder（策略叠高）/ Run（心算跑酷）——同一套教具，三种玩法；SplashLearn 的游戏区刻意与进度报告脱钩（自由玩不计分）。
- 我们现状：**已有沙盒**，但只有一个自由玩模式。
- 怎么借：数学实验室拆成三个模式：自由玩（现有）、拼目标（给一个目标数/分数，拼出来）、爬梯子（用十格阵/分数块策略性地叠到目标数）。同一套组件，三种玩法，对 1–3 年级收益最大。
- 预期收益：改动小；DragonBox 证明同一套教具换玩法模式就能多撑很多使用时长。

## 8. 不要借鉴的

- **Photomath 式拍照解题**：替孩子解题，没有教学闭环；抄答案的担忧在作业帮的家长口碑里已经出现。我们的定位是"动手玩懂"，不是"拍照得答案"。
- **Prodigy 的 RPG 包装**：独立测试里自愿参与度最高（14 天主动玩 14 天），但每分钟数学量崩到约 30%（20 分钟里约 6 分钟做题），JHU 研究认为没有教学价值，孩子学会"猜得快、接着玩"。最多借轻量任务 framing，绝不让游戏层吃掉数学时间。
- **Brilliant 的连胜/联赛游戏化**：长期用户报告疲劳；我们的自评 + 间隔复习已经能驱动习惯，不需要联赛。
- **IXL SmartScore 的不对称扣分**：80–90 分以上答错扣 3–8 分、答对只加 1–2 分，挫败感有据可查（"惩罚感"）。如果加可见分数，扣分要对称，或用 Mangahigh 的奖牌制代替。
- **DreamBox 式的隐形 48,000 数据点/小时追踪**：重、隐私敏感，且其疗效证据是厂商口径。我们的 localStorage 只记自评和进度，不上传——保持这个原则。
- **视频课堆量**（洋葱 8000+ 节、NOBOOK 300+ 专题视频）：与我们"交互优先、可视化优先"的原则冲突；视频是用来补"讲知识"的手段，我们的"为什么 + 看图学 + 演示"已经覆盖了。
- **重游戏化 RPG**（NOBOOK 科学世界 RPG、Prodigy）：会分散学习注意力，且开发成本高。
- **付费墙卡内容**（免费版只给 20%、Brilliant 每天 2 把钥匙、IXL 每天 10 道题）：与我们免费开放冲突；且是家长社区的主要抱怨点。
- **电销/续费套路和按学段打包会员**（斑马、火花、洋葱的销售打法）：与产品无关，不借鉴。
- **"提分 70→90"式无对照个案宣传**（洋葱、洪恩等营销软文）：没有对照组，不能当作证据引用。
- **把数学做成"实验步骤背诵"**：科学实验有标准操作流程可评分；数学思维若变成背步骤，会扼杀我们 CPA + 讲回来的优势。分步评分要评"思路步骤"，不是"操作步骤"。
- **Copyleft 代码**：GCompris（AGPL-3.0）、Álgebra 3D（GPL-3.0）、Anki（AGPL-3.0）——只借想法，不要把代码抄进 app，除非接受 copyleft 条款。用 ts-fsrs 代替 Anki。
- **已停用/停滞的产品**：Microsoft Math Solver（2025 年 7 月停用）、Mangahigh（2025 年 12 月 31 日永久关闭）、瓜瓜龙思维（2021 年后无运营证据）、有道数学（遗留产品）——不要对标，不要引用。

## 9. 未验证清单（必须如实记录）

1. 各 App 的 App 内实际交互细节（如斑马答错时的具体动画、火花课件内的具体拖拽操作、DreamBox/Zearn 的 ESSA 条目原文）——官方只给宣传描述，无公开可看的交互录屏；B 站/抖音的所谓演示多为搬运课程合集或营销号剪辑，非官方机制演示。建议后续用真机/浏览器实测 2–3 个候选（优先：小猿AI、洋葱学园、都都思维）再定借鉴清单。
2. 价格均为 2026 年 11 月检索到的公开报价，促销浮动大，仅供参考；Symbolab Pro 和 DragonBox 订阅价在不同来源间不一致，引用前以官网为准。
3. "AIGYM"（Mangahigh 名下）：任何来源里都没有找到；Mangahigh 的自适应引擎叫 Prodigi。不要把 AIGYM 当成真实机制。
4. DreamBox 和 Zearn 的 ESSA/WWC 条目原文未逐条核对；Matific 的"34%"是 8 所学校的小样本标题，不是可推广效应；Mathletics NAPLAN 报告里的 Cohen's d 4.52/5.98 大得不合常理，很可能是标错了，持怀疑态度。
5. GitHub 部分：mathjs、KaTeX、ts-fsrs、MathLive、CindyJS、Manim Community 的精确最后提交日期只验证到"2026 年活跃"（release、npm 版本、维护徽章）；@mathigon/* npm 库的许可证、MicroSkill Arcade 的 star 数未直接验证。复用前逐个确认。
6. 抖音/西瓜视频 App 内搜索未做（通用搜索引擎不收录短视频站内内容）；小红书站内链接无法直接检索，家长反馈来自二次引用。
7. 悟空数学有两个同名产品（幼儿 App vs 悟空国际数学直播课），无任何关联——引用时必须区分。
8. 本报告第 5 节的开源发现与并行的 GitHub 开源专项调研（`docs/research/github-math-opensource-20261106/`，commit c6f9a9d）有重叠也有互补：专项报告多验证了 kenowong/math-mastery（MIT，409★，单文件离线、参数化出题引擎 qgen）和 edu-ai-builders/math-viz-kit（无许可证，90★，123 个单文件可视化 + 8 条学习科学规则），以及 FSRS 的 UMD 构建可直接内联进单文件 HTML 的结论；本报告的开源部分以机制对照为主，两份报告应一起读。
