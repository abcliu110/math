# Interactive Animations for Mathematical Operations (Grades 1–9) — Worldwide Collection

**Scope:** Interactive animations (student-manipulable, not just video) that teach each operation, Chinese + international sources, Grades 1–9 (ages 6–15). Researched 2026-11-06. No sign-in used; only public web sources.
**Confidence:** Core platforms (PhET, Polypad, Math Learning Center, Math Curious, MiniWebtool, NovaMath) verified via `browser_open` on 2026-11-06; the rest are index (search-result) evidence, flagged as such. The live research browser failed in this run (`page_gone`, no tabs), so no in-window click-through verification was possible — see "Could not verify".
**How to read the tables:** *Student action* = what the child physically does; *Mechanism* = the exact interaction that teaches the operation; *Free?* = free / free-tier / paid as stated on the source page.

## PART 2 — DESIGN METHODS (reusable, with examples)

1. **Regrouping = breaking/joining a physical unit.** 10 ones looped/snapped into a ten rod; a ten smashed into 10 ones. *Examples:* Math Curious Addition Build / Subtraction Smash — https://mathcurious.com/tools/ ; MySchoolHero Regrouping Lab — https://www.myschoolhero.com/regrouping-lab.html
2. **Make-ten = move counters to fill a ten-frame, then add the rest.** The moved counters are the mechanism; the "10 + 3" is what remains. *Examples:* PhET Make a Ten — https://phet.colorado.edu/es_PE/simulations/make-a-ten ; Number Sense Maths — https://numbersensemaths.com/nff/sample-resources-nff/sample-animations
3. **Division = dealing into equal groups, leftovers stay visible.** Drag objects one-by-one into groups; the un-dealt remainder is the remainder. *Examples:* SplashLearn — https://www.splashlearn.com/s/math-games/divide-objects-into-equal-groups ; JustRevise — https://www.justrevise.in/labs/maths/division
4. **Long division = repeated subtraction with a running remainder.** Number-line jumps of the divisor, or divide–multiply–subtract–bring-down per digit in an animated bracket. *Examples:* MiniWebtool — https://miniwebtool.com/long-division-calculator/ ; Brainingcamp repeated-subtraction demo — https://www.instagram.com/reel/DY0OnTnE06B/
5. **Common denominator = bars that must be cut to the same size before they can join.** Overlay smaller slices on bigger ones until pieces match. *Examples:* Woot Math — https://www.wootmath.com/practice/free-tier-grade-5 ; Math Curious Add & Subtract Fractions — https://mathcurious.com/tools/
6. **Fraction × fraction = "of" as overlapping shading.** Shade one fraction in columns, the other in rows; the double-shaded overlap is the product. *Examples:* Math Curious — https://mathcurious.com/blog/multiply-divide-fractions-area-models-fraction-bars/ ; PhET Area Model Decimals (same geometry for decimals) — https://phet.colorado.edu/en/simulations/area-model-decimals
7. **Fraction ÷ fraction = "how many divisor-pieces fit in the dividend".** Lay the divisor bar along the dividend bar repeatedly; count fits; leftover is a fraction *of a piece*. *Example:* Math Curious — https://mathcurious.com/blog/multiply-divide-fractions-area-models-fraction-bars/
8. **Decimal × decimal = tenths × tenths grid, overlap = hundredths.** 10×10 grid; colour rows × columns; purple overlap cells counted as hundredths. *Examples:* NovaMath — https://www.novamath.org/tools/decimal-multiplication-model.html ; PhET Area Model Decimals — https://phet.colorado.edu/en/simulations/area-model-decimals
9. **Distributive law = splitting a rectangle.** Drag a partition line; each sub-rectangle is a partial product; total = sum. Works for whole numbers, decimals, algebra. *Examples:* PhET Area Model Multiplication — https://phet.colorado.edu/en/simulations/area-model-multiplication ; Array Builder split — https://games.successtutoring.com/nz/array-builder-game/
10. **Commutative law = turning the array round.** Same objects, rows↔columns; the count doesn't change. *Example:* Array Builder — https://games.successtutoring.com/nz/array-builder-game/
11. **Equation = a balance; solving = doing the same thing to both sides.** Drag tiles on/off a pan balance; remove zero pairs; split into equal groups. *Examples:* PhET Equality Explorer — https://www.mathmammoth.com/practice/equality-explorer ; NLVM — http://nlvm.usu.edu/en/applets/doc/balancedequation/help.html ; Polypad Balance Scale — https://polypad.amplify.com/
12. **Vertical algorithm = concrete and abstract side-by-side, in lockstep.** Blocks regroup on the left; the carried/borrowed digit appears in the column on the right at the same moment. *Examples:* Brainingcamp — https://www.brainingcamp.com ; MiniWebtool vertical calculator — https://miniwebtool.com/zh-cn/%E7%AB%96%E5%BC%8F%E5%8A%A0%E5%87%8F%E6%B3%95%E8%AE%A1%E7%AE%97%E5%99%A8/

**How wrong moves are shown (found):** Math Curious Multiply & Divide Fractions: answering 2/3×3/4 as 5/7 gets *"Don't add the tops and bottoms. Count the green parts and all the parts."*; a wrong cut gets *"Cut into 4 or 3 columns: the bottom number of one of the fractions."*; answering 11/12÷3/4 as 1 2/12 gets a hint that the leftover is 2/9 *of a piece*. Math Curious Order Up!: adding before multiplying is flagged with a hint ("Multiply and divide before you add and subtract"). PhET sims generally give no verbal correction — the model simply doesn't fit / doesn't balance, which is itself the feedback (e.g. unequal pieces can't be added in Woot Math; an unbalanced scale tips in Equality Explorer). **Not found:** a wrong trial quotient shown as overshoot in long division; adding numerators/denominators shown as pieces that physically don't line up (only described, not built, except in Woot Math's overlay).

## Chinese vs International — summary split

- **International (English):** Dominated by free, no-login, research-based sims — PhET (Colorado), Polypad/Mathigon (Amplify), Math Learning Center, NLVM, Desmos — plus paid-but-excellent operation-specific games (Math Curious via TpT, Brainingcamp, DreamBox, Woot Math). Mechanisms are student-manipulable and often show wrong moves.
- **Chinese (incl. Taiwan):** Strongest free source is **均一教育平台 Junyi Academy** (Taiwan, nonprofit, free: animated worked examples 【素養動畫】 + stepped practice for fractions, decimals, 直式, mixed operations). Mainland: **国家中小学智慧教育平台** (free, textbook-synced micro-lessons — video-led, not manipulable), **洋葱学园** (paid app, 5-min animation lessons with in-video clicks), **希沃白板** (teacher-authored interactive whiteboard, not a fixed student sim), and free **calculator-style vertical tools** (MiniWebtool Chinese version, CalcSprint, Calcbe, 61me). **No mainland free web sim was found where the student manipulates regrouping / common denominators / trial quotient themselves** — that is the clearest China-side gap.
