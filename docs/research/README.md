## 4. NB实验室（NOBOOK 虚拟实验平台）

`nb-lab-20261106/report.md`

- 国内做得最久的中小学理化生虚拟实验平台：核心不是实验视频库，而是可自由组装的器材 + 实时计算的物理/化学引擎 + 按步骤打分的模拟考试。
- 机制拆解：2000+ 教材同步实验、1000+ DIY 器材、8 大引擎（电学基于基尔霍夫定律，任意接线都有对应结果）、练习/考试双模式、按步骤给分 + 丢分定位 + 综合统计、AI 伴学、五步学习法、RPG/闯关、教师端。
- 一个实验到底怎么玩：以“伏安法测电阻”为例重建全流程（选器材、搭电路、练习模式、做错了会怎样、考试模式出报告），对照福州中考实验评分表。
- 可借鉴到数学 App 的 10 条点子（按价值排序）：按解题步骤给分 + 丢分定位、练习/考试双模式、数学实验室自由沙盒、错误可视化、五步学习法、数学史彩蛋、错题本升级成体检表、试卷题反查知识点、轻量虚拟收集、轻量家长看板；不借视频课、重度 RPG、付费墙、3D 高仿真。
- 未核实：2000+ vs 700+ 实验数口径、引擎算法细节、AI 伴学质量、畅学卡人民币价、Web 端免登录体验。

## 5. NB数学实验（NOBOOK 数学产品）

`nb-math-lab-20261106/report.md`

- 核心结论：**没有找到任何证据表明它是一个已经上线、可用的数学产品**——唯一可确认的痕迹就是 open.nobook.com 上的一张产品卡；官网、应用商店、新闻、Bilibili、YouTube、抖音、小红书、微信文章全都只讲理化生，不提数学；官网著作权清单里有语文，没有数学。最可能的解释是未上线的新产品占位卡，或仅对合作方开放的入口。
- 视频站重点核查：Bilibili “NB数学实验”相关视频 0 个；搜到的 NB实验室视频全是化学沙盒玩法（把所有液体药品混在一起、卡 bug 白嫖 VIP），恰恰说明 NOBOOK 最吸引人的是“自由组合、即时看后果”，不是按步骤做实验。
- 数学“实验”怎么写不出来：年级、主题、工具、流程、定价全都查不到，报告不编造假 walkthrough；第 3.1 节的类比推断明确标注不可当事实引用。
- 可借鉴的 7 条（按优先级）：数学沙盒/自由探究模式（最高，我们最缺）、错误可视化、分步评分 + 丢分定位、练习 vs 考试模式、教师/家长端 + 探究作业（远期）、闯关式知识路径（显性化）、“发现时刻”小故事；不要借视频课堆量、重游戏化 RPG、付费墙、把数学做成实验步骤背诵。
- 我们已经比它好的地方：142 条知识点 + 三级 ladder、学习科学机制（提取/间隔/交叉/元认知）、完全免费无登录。
- 未验证：点开 NB数学实验 卡片后发生什么（需真浏览器点一次）、NB信息科技卡、抖音/西瓜 App 内搜。
