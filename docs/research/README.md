## 4. NB实验室（NOBOOK 虚拟实验平台）

`nb-lab-20261106/report.md`

- 国内做得最久的中小学理化生虚拟实验平台：核心不是实验视频库，而是可自由组装的器材 + 实时计算的物理/化学引擎 + 按步骤打分的模拟考试。
- 机制拆解：2000+ 教材同步实验、1000+ DIY 器材、8 大引擎（电学基于基尔霍夫定律，任意接线都有对应结果）、练习/考试双模式、按步骤给分 + 丢分定位 + 综合统计、AI 伴学、五步学习法、RPG/闯关、教师端。
- 一个实验到底怎么玩：以“伏安法测电阻”为例重建全流程（选器材、搭电路、练习模式、做错了会怎样、考试模式出报告），对照福州中考实验评分表。
- 可借鉴到数学 App 的 10 条点子（按价值排序）：按解题步骤给分 + 丢分定位、练习/考试双模式、数学实验室自由沙盒、错误可视化、五步学习法、数学史彩蛋、错题本升级成体检表、试卷题反查知识点、轻量虚拟收集、轻量家长看板；不借视频课、重度 RPG、付费墙、3D 高仿真。
- 未核实：2000+ vs 700+ 实验数口径、引擎算法细节、AI 伴学质量、畅学卡人民币价、Web 端免登录体验。
- 授权注意：NOBOOK 是商业闭源产品，只学机制与思路，不复制任何文字、图片、视频、代码、界面。
