# 数学小宇宙 · 菜单与导航规范

> 来源：借鉴 Iris 的汉字 App（`abcliu110/hanzi-app`，`newhanzi/`）的导航与面板设计。
> 学的是结构、布局和交互方式，不是抄它的代码、文案、配色或品牌。
> 汉字 App 的规范原文在 `/tmp/hanzi-app/newhanzi/FRONTEND_UI.md` 第 7 节，
> 核心实现在 `/tmp/hanzi-app/newhanzi/nav-up.js`。
> 汉字 App 源码文件参考：`newhanzi/index.html`（首页面板 + 模块页顶栏）、
> `newhanzi/zika.css`（`.home-view .panels`、`.panel`、`.topbar`、`.back`、`.crumb`）、
> `newhanzi/FRONTEND_UI.md`（颜色 token、断点、导航 §7）。

## 1. 硬性规则：逻辑导航，不靠浏览器历史

这是从汉字 App 照搬过来的硬性规则，数学 App 必须遵守：

1. **全站统一一套返回 / 前进**，新页面和改动都必须遵守。
2. **每个页面只有一个返回入口**：顶栏最左边，文字统一为「← 返回」。
   返回回**上一级**，不回首页；只有在模块最外层时，返回才回首页。
   页面内容区不再另放返回按钮。
3. **面包屑**：顶栏标题显示当前层级，例如：`数学 › 选年级 › 3 年级`、
   `数学 › 换维度 › 内容领域`、`数学 › 互动演示 › 分数切一切`。
   面包屑的每一级都可以点，点哪一级就回到哪一级；最后一级是当前页，不可点。
4. **只用界面层级，不用浏览器历史**：禁止用浏览器历史 API 实现页面导航
   （汉字规范原文列出的调用：`history.back()`、`history.go()`、
   `history.pushState()`、`history.replaceState()`、`popstate`）。
   汉字 App 的做法是：子页声明自己的层级和回各级的函数
   （`NHZNavPage.set(['一级','二级'], [回一级的函数, null])`），
   父页用命令（`postMessage` 发 `up` / `go`）让子页回到指定层级。
   数学 App 是单页原型，等价做法是：**一个导航状态机 / 层级栈**（见 §3），
   记录当前层级和每级的进入函数，返回和面包屑都调用这些函数切换视图，不碰浏览器历史。
5. **菜单、面板、首页按钮的每一次跳转都是逻辑跳转**（调 `navGo()`），
   不靠锚点 `href="#grades"` 这类只靠浏览器滚动 / 历史的写法。
   原有的锚点写法已全部改掉：顶栏链接、品牌链接、首页两个大按钮都改成了按钮 + `navGo()`。

### 验收（照汉字 App §7.5）

- 每个页面顶栏只有一个返回，内容区没有返回按钮。
- 进两级以上后，点返回能回上一级，点面包屑能回对应层级。
- 代码和测试里不得出现浏览器历史的导航调用。
  （`app.js` 里连注释都避开了这些调用名，只在本文档里写出禁止清单。）

## 1a. 没有侧边栏，菜单层级全部用面板表示（Iris 2026-11-06 的要求）

**不要侧边栏。**桌面和 tablet 都没有侧边栏，也没有抽屉、没有 `☰ 菜单` 按钮、
没有遮罩。主界面通栏，菜单的每一级都是一组面板（大卡片：图标 + 标题 + 副文 +
进度条 / 计数），点一块面板进下一级：

| 层级 | 面板组 | 点一块后 |
|---|---|---|
| 首页 | `#panels`：选年级、换维度、学习路径、互动演示、错题本、我的进度 | 进对应模块 |
| 选年级 | `#gradePanels`：1–9 年级面板（年级 + 小学/初中 + 单元数） | 进该年级，只显示该年级详情，年级面板藏起来 |
| 换维度 | `#dimPanels`：5 个维度面板（内容领域、认知层次、核心素养、前置关系、问题类型） | 进该维度，只显示该维度的分组内容，维度面板藏起来 |
| 学习路径 | `#pathPanels`：动手试一试、说一说、练一练、测一测 | 进该步，只显示该步面板 + 一段说明（`#pathDetail`） |
| 互动演示 | `#demoPanels`：分数切一切、天平解方程、函数 k / b 滑杆、为什么小实验 | 进该演示卡片，只显示该卡片；为什么小实验只显示 `#why` 区 |
| 错题本 / 我的进度 | 首页的两块面板是导航入口（占位内容不变） | 进 `#review` 区，只显示对应的那张卡片 |

面板不是列表、不是侧边栏的子项：每级菜单的唯一表现形式就是面板。
`grep sideNav|menuToggle|navOverlay|navGrades` 在 `apps/web/` 里必须为零；
样式里也不得残留 `.sidenav` / `.menu-item` / `.nav-overlay` / `.app-shell` 两列布局。

## 1c. 视图隔离：首页不露出内容，点面板才看得到（Iris 2026-11-06 的要求）

**在菜单下面不显示内容。**首页只显示顶栏、主界面模式栏、首页介绍和首页面板；
年级、维度、学习路径、演示、为什么、错题本、进度、下一步、页脚这些模块内容，
在首页一律藏起来，往下滚动也看不到。必须点一块面板，才能看到它对应的内容。

| 当前视图 | 看得到什么 | 藏起来什么 |
|---|---|---|
| 首页（默认打开） | 顶栏、模式栏、首页介绍、首页面板 | 全部模块区：`#grades`、`#dimensions`、`#path`、`#demos`、`#why`、`#review`、下一步、页脚 |
| 选年级 | 9 块年级面板 | 首页、年级详情、其他全部模块 |
| 某年级（如 3 年级） | 只有该年级的详情 | 年级面板、首页、其他全部模块 |
| 换维度 | 5 块维度面板 | 首页、维度分组内容、其他全部模块 |
| 某维度（如内容领域） | 只有该维度的分组内容 | 维度面板、首页、其他全部模块 |
| 学习路径 | 4 步面板 | 首页、步骤说明、其他全部模块 |
| 某一步（如说一说） | 只有该步的面板 + 一段说明 | 其他三步面板、首页、其他全部模块 |
| 互动演示 | 演示面板 | 首页、演示卡片、其他全部模块 |
| 某演示（如分数切一切） | 只有该演示卡片 | 其他演示卡片、演示面板、首页、其他全部模块 |
| 为什么小实验 | 只有 `#why` 区 | 演示区、首页、其他全部模块 |
| 错题本 / 我的进度 | 只有对应的那张卡片 | 另一张卡片、首页、其他全部模块 |

实现：`app.js` 的 `applyView()`，`renderNav()` 每次都调它，按导航栈顶算出视图
（`viewForKey()`），逐项设 `hidden`；样式里 `[hidden]{display:none !important}`，
因为 `.panels` / `.hero` 的 `display` 规则会盖掉浏览器对 `hidden` 的默认样式；
`body[data-view]` 的 CSS 规则是第二道防线。进入各级时不再按目标滚动，
直接回到页顶（`enterNavEntry()` 里 `window.scrollTo({top: 0})`），因为一次只有一个视图，
内容本来就在页顶。返回 / 面包屑 / 点品牌回首页时，`applyView()` 重新算视图，
模块内容重新藏起来，上一级面板再出现。下一步和页脚在视图隔离后不再出现。

## 1b. 模式切换放哪里（Iris 2026-11-06 的要求）

模式切换（按年级 / 按维度，以及 5 个维度按钮）**直接放在 App 主界面上**：

- 位置：`<main>` 顶部、顶栏正下方的常驻模式栏（`#modeBar`，吸顶，`top: 64px`），
  里面是分段控件「按年级 / 按维度」，按维度时同一行展开 5 个维度按钮
  （内容领域、认知层次、核心素养、前置关系、问题类型），48px 以上热区，
  平板横向滚动、桌面换行。点一个维度，`#dimensions` 的内容区就按该维度重分组，并滚到该区。
- **不在侧边栏**：根本没有侧边栏；模式切换只在主界面的模式栏里（见上）。
- **不在测试栏**：原型里没有测试栏，也不加测试栏；切换器就是正式界面的一部分。
- 全页只有这一份维度切换器：`#dimensions` 区里原来的 `dim-bar` 已移进模式栏，
  该区只留内容显示（`#dimDetail`）。
- 同步：`updateModeUI(mode)` 管模式栏的选中态和维度按钮行的显隐；
  选年级、进维度视图、点维度按钮都会调它，所以无论从哪里进来，模式栏状态都和当前视图一致。

| 汉字 App 的做法 | 数学 App 的对应做法 |
|---|---|
| 首页是品牌 + 今日进度条 + 一组大面板卡片，每块面板有图标、标题、副文、进度条和计数，点一块进一个模块 | 首页保留品牌与进度，新增「从这里开始」面板区：选年级、换维度、学习路径、互动演示、错题本、我的进度，同样是图标 + 标题 + 副文 + 进度条 + 计数，点一块调 `navGo()` 进模块 |
| 模块页顶栏：最左一个醒目的返回按钮，旁边是标题 + 副标题，标题可展开成可点面包屑 | 顶栏：最左「← 返回」，旁边是面包屑标题，当前级不可点，前面各级可点 |
| 导航只用界面层级，返回回上一级，面包屑点哪级回哪级；支持 `?m=模块名` 直达 | 单页层级栈 `navStack` + `navGo()` / `navBackFn()` / 面包屑点击，见 §3；暂无 `?m=` 直达参数 |
| 断点 ≥768px 平板、≥1200px 桌面，内容 max-width 约 1100–1200px 居中；顶栏 sticky；按钮最小热区 48–52px；焦点 3px 描边 | 同样断点思路，**但没有侧边栏**（见 §1a）：桌面和平板都是通栏内容；内容 max-width 1120px；顶栏 sticky；面板、按钮最小 48px，平板 52px；焦点 3px 描边 |
| 面板卡片：圆角 18px、描边、悬停上浮 + 阴影、进度条 5px | 面板卡片沿用数学 App 自己的橙色配色和圆角，同样是悬停上浮 + 阴影、5px 进度条 |

没有抄的东西：汉字 App 的颜色 token（护眼绿）、品牌名、图标、文案、代码
（`index.js` 的 `openModule` / `postMessage` 实现）、字库与题目数据。

## 3. 导航状态机（`app.js`，`NAV_DEFS` / `navStack`）

- `NAV_DEFS[key]`：每一项的定义 = 面包屑路径 `crumbs`、滚动目标 `target`、
  进入时要做的事 `action`（可选）、高亮目标 `flash`（可选）。
  年级子项（`grade-1` … `grade-9`）和维度子项（`dim-domain` …）由 `GRADES` /
  `DIMENSIONS` 数据自动生成，`action` 分别是 `selectGrade(g)` / `renderDimension(id)`。
- `navStack`：层级栈，初始只有 `[{ key: 'home', crumbs: ['数学'] }]`。
  - `navGo(key)`：同级重复点只重新进入（调 `action` + 滚动），不重复入栈；
    新级入栈后进入；`home` 清空栈回根。
    同一族内切换（维度换维度、年级换年级）替换栈顶，不层层入栈；
    从某维度回「换维度」这一级、从某年级回「选年级」这一级时回到父级，不再入栈一层。
    进叶子级时先补上父级（`parentOf()`：`grade-N` → `grades`、`dim-*` → `dimensions`、
    `path-step-N` → `path`、`demo-*` / `why` → `demos`）：从首页点 3 年级面板，
    栈是 `[首页, 选年级, 3 年级]`，面包屑里的每一级都是栈里的真层级，点面包屑的父级能跳回去；
    跨分支跳转时从首页重开一条路，不把旧分支留在面包屑里。
    `goDimension()` 同理：从首页点模式栏的维度，栈是 `[首页, 换维度, 某个维度]`。
  - `setModeView(mode)`（模式栏专用）：模式切换不是入栈一级，而是跳到顶层视图——
    按年级回到 `[数学 › 选年级]`，按维度回到 `[数学 › 换维度]`；
    这样从维度切回年级后，点「← 返回」不会又掉回维度里。
  - `goDimension(id)`（模式栏维度按钮专用）：已在维度分支内就替换栈顶，
    不在就从首页直接进该维度；面包屑始终是「数学 › 换维度 › 某个维度」。
  - `navBackFn()`：栈深 > 1 时弹出栈顶，进入新的栈顶；栈深为 1 时什么都不做
    （首页本来就没有返回按钮）。
  - 面包屑点击：把栈截断到被点的那一级，再进入那一级。
  - 每次进入都做三件事：调本级的 `action`、回到页顶、
    有 `flash` 时给目标描边高亮 1.6 秒；然后 `renderNav()` 重画返回按钮、
    面包屑和菜单高亮，并调 `applyView()` 按栈顶切换视图（见 §1c），
    一次只显示一个视图。
- `renderNav()`：栈深 ≤ 1 时返回按钮 `hidden`；否则显示。
  面包屑按栈顶的 `crumbs` 渲染，前面的级是按钮（带 `data-crumb` 序号），
  最后一级是不可点的当前级。当前菜单项设 `aria-current="true"`。

## 4. 菜单结构（全部是面板，没有侧边栏）

顶栏：`← 返回`（唯一返回入口）· 品牌（点它回首页）· 面包屑标题 · 进度芯片（已体验演示数）。
没有 `☰ 菜单` 按钮，没有抽屉，没有遮罩。

| 层级 | 面板组 | 面板项 | 面包屑 | 目标 |
|---|---|---|---|---|
| 首页 | `#panels` | 选年级、换维度、学习路径、互动演示、错题本、我的进度 | 数学 | 页顶 |
| 选年级 | `#gradePanels`（由 `GRADES` 生成） | 1 年级 · 小学 … 9 年级 · 初中 | 数学 › 选年级 › N 年级 | 只显示该年级详情（`#gradeDetail`），年级面板藏起来 |
| 换维度 | `#dimPanels`（由 `DIMENSIONS` 生成） | 内容领域、认知层次、核心素养、前置关系、问题类型 | 数学 › 换维度 › 维度名 | 只显示该维度的分组内容（`#dimDetail`），维度面板藏起来 |
| 学习路径 | `#pathPanels` | ① 动手试一试、② 说一说、③ 练一练、④ 测一测 | 数学 › 学习路径 › 某一步 | 只显示该步面板 + 说明（`#pathDetail`） |
| 互动演示 | `#demoPanels` | 分数切一切、天平解方程、函数 k / b 滑杆、为什么小实验 | 数学 › 互动演示 › 演示名 | 只显示该演示卡片（`.demo-grid` 里只留一张）；为什么小实验只显示 `#why` |
| 复习与进度 | 首页的错题本、我的进度面板 | 错题本、我的进度 | 数学 › 错题本 / 我的进度 | 只显示对应的那张卡片（`#reviewCard` / `#progressCard`） |

其中「换维度」首页面板只是导航入口（调 `navGo('dimensions')` 进维度视图），
真正的模式切换器在主界面顶部的模式栏里（见 §1b），不在侧边栏、不在面板里。

### 平板 vs 桌面

- **桌面（> 1024px）和平板（≤ 1024px）都没有侧边栏**：主界面通栏，内容 `max-width 1120px` 居中；
  面板区桌面三列、平板两列，按钮最小 48px，平板 52px。
- **小屏（≤ 700px）**：面板两列，品牌副文隐藏，面包屑字号收小。
  （手机不是目标设备，照汉字 App 的决定：只做平板和桌面。）
