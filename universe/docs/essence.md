# 数学的本质，与实验室怎么揭露它

目标不是“能算”，而是让学生亲手碰到数学**为什么是这样**。这份文档先列本质，再对照器材，再说计划。写给自己看，所以对缺口直说。

## 一、七种本质

| 本质 | 一句话 | 学生该亲手碰到什么 |
|---|---|---|
| 递推与结构 | 下一步由上一步决定 | 自己接出“上一个值→下一个值”的环，看数列长出来 |
| 守恒与等价 | 变形而不变的东西 | 两边一样重；通分是换一把尺子；面积剪拼后不变 |
| 规律与证明 | 例子给证据，推理给“一定” | 试很多例子，再被问“凭什么一定” |
| 变量与任意性 | 字母代表“任意一个” | 同一个式子代入许多数，都成立 |
| 极限与大数 | 单次不可测，大量有规律 | 掷 400 次，平均数稳到 7 |
| 表示与变换 | 同一个东西的多种样子 | 分数/小数/百分数；方程组 = 两条线相交 |
| 反例 | 一个反例推翻一切 | 试到第 40 个，发现 n²+n+41 不是质数 |

## 二、现有器材各碰到哪些

| 本质 | 触及的器材 | 触及程度 |
|---|---|---|
| 递推与结构 | 记忆器 + 时钟 + 运算器；两辆车 | 真实：学生自己接环 |
| 守恒与等价 | 平衡器；分数条（通分） | 部分：平衡有，剪拼没有 |
| 规律与证明 | 猜想与反例（新） | 只做到“证据”一半，“为什么”那一半没有 |
| 变量与任意性 | 猜想与反例（式子里的 n） | 刚起步；其余器材的 a、b、k 都是具体的数 |
| 极限与大数 | 骰子 + 直方图 + 统计量；硬币；袋子 | 真实 |
| 表示与变换 | 直线 + 交点；数字/分数条；进制 | 部分 |
| 反例 | 猜想与反例（新） | 真实，但只有 5 条内置“说法” |

只读公式结果、不揭露什么的器材：正多边形、长方体、三角形的角、圆、取整、数位板、不等式、数的性质。它们是“能算的演示”，学生调参数读数，看不到来历。

## 三、新器材计划

| 器材 | 揭露的本质 | 做法 | 状态 |
|---|---|---|---|
| 猜想与反例 | 规律与证明、反例、变量 | 学生写关于 n 的式子，器材逐个试 n，找到第一个反例就亮红；每次提醒“例子不是证明” | **已做**（5 条内置命题，3 道题） |
| 剪拼 | 守恒与等价 | 把图形剪开重排，面积/内角和不变；需要“多边形/点线”值类型 | 未做 |
| 符号与变量 | 变量与任意性 | “表达式”值类型；化简、展开、代入许多数检验是否恒等 | 未做（猜想器里的小解析器是起点） |
| 动态几何 | 表示与变换 | 点、线、圆可拖，量跟着变，找不变量 | 未做，需要点线值类型 |
| 证明台 | 规律与证明 | 学生把“因为…所以…”连成一条链，系统检查每步可由前一步得出 | 只在设计里 |

## 四、诚实的缺口

- 猜想器只有 5 条内置命题；学生还不能自己提出命题（应与“学生出题”打通）。
- “为什么”还靠 `why` 文字告诉学生，不是学生发现的。
- 试例子只能到 n=500，且只是整数 n。
- 几何的本质（剪拼、全等、相似）基本是空白，要先加新的值类型。
