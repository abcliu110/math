# 一个道理，几种样子：联动与本质页设计（先做“平衡”）

> 状态：2026-11-26 已确认，按第八节的建议做（入口叫“道理地图”，页面叫“两边一样：四种样子”；数轴用“试的数 g”；括号放第二版）。对应排队里的“增强3 联动”和“本质地图 + 本质页”。
> 目标一句话：**同一个等式，同时摆成天平、式子、线段图、数轴四种样子；在任何一种上做一步，另外三种当场做同一步。**

## 一、孩子看到什么

打开“平衡”这一页（孩子看到的名字见第八节），台面上是一道题，比如 **2x + 3 = 11**，四块并排（宽屏 2×2，窄屏上下排）：

| 样子 | 画成什么 | 在这一块上怎么做一步 |
|---|---|---|
| **天平** | 左盘 2 个盒子 + 3 个砝码，右盘 11 个砝码 | 已有的拖法：拖走砝码 / 盒子、平分（现成的天平与方程操作台） |
| **式子** | `2x + 3 = 11`，下面一行一行往下写，每行旁边写这一步做了什么（“两边 −3”） | 点一个项，弹出“两边都减 3 / 只这边减 3”；“两边 ÷2” 按钮 |
| **线段图** | 上面一条：2 段 x + 一截 3；下面一条：长 11。按真实长短画，等长时两条右端对齐 | 剪掉右端一截（两条一起剪）；把两条都平分成几份留一份 |
| **数轴** | 孩子拖一个“试的数” g；左边从 0 起跳 2 下（每下 g）再跳 3，右边落在 11；两个落点同时画出来 | 两个落点一起往左拖 3（= 两边 −3）；“两边 ÷2” |

做一步以后：

1. 四块**同时**变成 `2x = 8` 的样子，刚改的地方闪一下（天平少的砝码、式子新的一行、线段图剪掉的那截、数轴落点移过去的弧）。
2. 底下一条**共用的步骤栏**写：“第 1 步：两边同时减 3（在天平上做的）”。四块的步骤栏是一条，不是四条。
3. 撤销一次，四块一起退回去。

**故意只动一边**（关掉“两边一起动”或选“只这边”）：

- 天平歪；式子写成 `2x + 3 ≠ 8`，标红；线段图两条右端对不齐，差的那截标出来；数轴两个落点分开，中间标“差 3”。
- 四块用各自的样子说同一件事：**不平了**。再去另一边补上同一步，四块一起回来。这就是 essences.md 说的“可违反”：违反的后果在四种样子里同时看见。

**解出来**（一边只剩一个 x，另一边只剩数）：四块都定格。天平盒子上显示 4；式子最后一行 `x = 4`；线段图一段 x 和 4 对齐；数轴上 g 拖到 4 时两个落点重合（不在 4 时也能看到“差多少”，所以数轴这一块同时是“试一试”的入口）。

## 二、为什么数轴用“试的数”

天平和线段图可以拿藏着的真实值 x₀ 来画（天平要知道往哪歪，线段要知道多长），画面不会直接写出 x₀。数轴不一样：如果拿 x₀ 画，从 0 跳一下 x 就落在刻度 4 上，答案直接露出来。所以数轴这一块不用 x₀，用孩子自己拖的 g：

- 两边各按 g 算出落点，重合就说明 g 是解；
- 两边同时 −3，两个落点一起往左走 3，**差不变**；两边同时 ÷2，差也变成一半。“做同样的事，相等的还相等，不等的差按同样的方式变”，在数轴上看得最清楚；
- 这一块把“平衡”（E4）和“字母是任意一个数”（E8）连起来：g 换来换去，等式只在一个地方成立。

## 三、底层：共享的“等式状态”（增强3 的通用部分）

现在的连线是单向的：上游输出驱动下游属性，被驱动的属性不能手动改。四块互相联动做不成这样，所以新加一个概念：**联动组**。

```
scene.groups = [{ id: 'g1', form: 'lineq', state: { a:2, b:3, c:0, d:11, x0:4 }, members: ['天平1','式子1','线段1','数轴1'], log: [...] }]
```

- **form（样子的种类）** 是一类共享状态，第一个是 `lineq`：`a·x + b = c·x + d`，外加藏着的 x₀。以后 E3 的“同一个分数”就是另一个 form（`frac`：分数条 / 数轴找位置 / 面积模型 / 小数）。
- **每台器材写一个适配器**（登记在 form 下，不改器材本身的 compute）：
  - `toState(props) → state`：从这台器材的属性读出共享状态；
  - `fromState(state, props) → patch`：共享状态变了，这台器材的属性该改成什么；
  - `can(state) → null | '为什么画不了'`：这台器材能不能表示这个状态（见第五节的范围）。
- **做一步的流程**（全在内核的一个动作里，撤销一次全回去）：
  1. 孩子在某一块上操作，走原来的 `set` / `params`；
  2. 内核发现这台器材在一个组里，用它的 `toState` 读出新状态；
  3. 新旧状态比较，得到**这一步是什么**（第四节的步子表）；
  4. 先问其他每台 `can(新状态)`；有一台画不了，整步不做，说出原因（“线段图画不了负数：先别减这么多”）；
  5. 都能画，就用 `fromState` 给其他每台算 patch，连同步子写进 `group.log`，一起提交。
- **组的状态只存一份**（在 `group.state`），器材属性是它的影子。存档、撤销、重放、来历都跟着组走。
- 被组管着的属性不再当成“正由连线驱动”而拒绝手改：改它就是在组里做一步。
- 来历：`explain` 能说出“式子这一行来自：天平上两边各拿走 3 个砝码（规则 eq.both-sides）”。

## 四、“同一步”的步子表（按规则 id 对齐）

新旧状态一比，就能认出是哪一种步子。每种步子在四块上的样子提前写好，闪的就是这一部分：

| 步子 | 规则 id | 状态变化 | 天平 | 式子 | 线段图 | 数轴 |
|---|---|---|---|---|---|---|
| 两边 −k | `eq.both-sides` (sub, k) | b−k, d−k | 两盘各拿走 k 个砝码 | 新一行，旁注“两边 −k” | 两条右端各剪 k | 两个落点各左移 k |
| 两边 +k | `eq.both-sides` (add, k) | b+k, d+k | 各加 k 个 | “两边 +k” | 各接一截 k | 各右移 k |
| 两边 −m 个 x | `eq.both-sides` (subx, m) | a−m, c−m | 各拿走 m 个盒子 | “两边 −mx” | 各剪掉 m 段 x | 各少跳 m 下 |
| 两边 ÷n | `eq.both-sides` (div, n) | 全部 ÷n | 平分成 n 份留一份 | “两边 ÷n” | 平分成 n 份留一份 | 落点都变成 1/n |
| 只动一边 | `balance.lone`（新登记） | 只改一边 | 歪 | `≠` 标红 | 对不齐 | 落点分开 |
| 挪过去 | `balance.move`（新登记） | 一边 −1 另一边 +1 | 拖到另一个盘 | 写两步：先“只这边 −1”，再“只那边 +1” | 同左 | 同左 |

认不出的变化（比如一下改了好几处）不让做，说“一次做一步”。

## 五、四块共同能表示的范围（如实写）

取四台器材的交集：

- `a, c` 是 0 到 6 的整数（天平最多 6 个盒子），`b, d` 是 0 到 30 的整数，x₀ 是 1 到 20 的整数；
- **没有负数、没有减号、没有括号、没有分数系数**（天平和线段图现在都画不了）；
- 线段图要改：现在最多 8 段、一段长 1 到 40，够用；“一段有多长”在联动时由 x₀ 定，孩子不能拖；
- 数轴要加一种用法“两边各走”（现在的四种用法都不是）：两条跳的路 + 一个可拖的 g，范围按两边最大值自动定；
- 式子块是新做的器材（现在的“方程卡”只能填字，不能一步一步做）。

括号、分数系数、负数、“移项为什么变号”是 balance.md 里还没做的几项，要等天平先能表示，再进联动。
