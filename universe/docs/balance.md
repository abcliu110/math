# 以“平衡”为例：从一个本质延展出的整张网

“平衡”的本质：**两边一样，做同样的事，仍然一样；破坏一边，就要有补偿。** 下面每一条线都是同一件事换了身份。

## 本质的统一表述
等式 = 平衡，操作 = 两边同施，解方程 = 逆着操作回到单独的 x，不等 = 歪，杠杆 = 乘积的平衡，守恒 = 变化中的不变量，公平 = 期望的平衡，对称 = 镜像的平衡，稳定 = 动态过程趋于平衡。
学生如果在这些场景里都能说出“两边在做什么”，就是真的理解了平衡。
