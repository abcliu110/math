# 创意清单（尚未实现）

按“能让实验室从课本演示变成探索未知的地方”排序。前三项不需要新的值类型，是现有框架的自然延伸。

1. **改规则的世界**：给学生“公理旋钮”——钟的模改成 2、三角形放到球面上（内角和 270°）、允许平行线相交。看哪些定理塌掉、哪些还成立。“为什么内角和是 180”只有在能改的世界里才有答案。
2. **黑箱侦探**：不透明的机器，只能喂数、看输出，写下猜想，系统用反例攻击。函数、数列、找规律都变成破案。
3. **简单规则长出复杂世界**：细胞自动机（规则 30、90、110），学生改规则看宇宙变样。
4. **器材倒着跑**：固定输出，问输入。解方程 = 把机器倒过来开。
5. **一数多面**：同一个数同时是点阵、长方形、数轴上的点、钟上的位置、质因数乘积，拖动一个其余联动。
6. **会唱歌的比**：3:2 是五度，同余钟是节拍器，复合节奏。用耳朵听分数和周期。
7. **博弈器材**：取石子，与电脑对打，发现“留 4 的倍数”必胜，再用同余钟解释。
8. **反直觉赌场**：生日悖论、三门问题，先猜再用骰子跑一千次。
9. **无穷旅馆**：数一数无穷，序列与映射。

系统层面（比再加器材更重要）：**容器**（把搭好的流水线封成新器材）、**本质标签**（每个器材标出它揭露的本质，用本质把题和器材串成知识网）、更多值类型（点线、表达式、集合）。
