# 本质设计：先想清楚数学是什么，再决定器材长什么样

> 这份文档是实验室的地基。以后每个器材、每道题，都要能回答：**它揭露哪一种本质？学生怎样动手碰到它？怎样判断他真的碰到了？**
> 回答不上来的，就只是“演示”，不进主线。

---

## 一、什么算“本质”

一个想法要称得上本质，要通过三道检验：

1. **跨场景**：能在至少三个看起来毫无关系的知识点里认出同一个结构。（例：“两边做同样的事不改变相等”出现在解方程、通分、面积剪拼、相似变换里。）
2. **可违反**：学生能故意破坏它，看到后果。（只动天平一边 → 歪；把三角形放到球面 → 内角和不是 180°。）违反后的后果，比正面演示更能让人明白它是什么。
3. **可迁移**：换一个场景，学生能自己认出来再用，不需要提示。

只满足“课本里有这一章”的，是知识点，不是本质。

---

## 二、本质目录（十二种）

每种写：一句话 · 学生该亲手碰到什么 · 数学上它是什么 · 在哪些知识点里出现 · 判据（怎样算真懂）。

### E1　对应（一一对应与映射）
- **一句话**：把一堆东西和另一堆东西配成对，不多不少。
- **碰到**：数苹果时一个一个点，配的是“数字”和“苹果”；点阵里一行一行配；两条线上的点互相对应。
- **数学**：映射、双射、函数的雏形；“数”本身就是对应（基数）。
- **出现**：计数、乘法（阵列）、函数、坐标、比例、集合大小比较、无穷旅馆。
- **判据**：能解释“为什么数的时候换个顺序，结果不变”；能找出一个对应里“多出来的”和“空着的”。

### E2　分解与组合（可加性与结构）
- **一句话**：大的由小的拼成，小的可以拆出来；怎么拆、怎么拼会影响看到什么。
- **碰到**：12 = 3×4 = 2×6 = 12×1，同一个量的多种拆法；多边形拆成三角形。
- **数学**：加法结构、因数、质因数分解、面积/体积累加、多项式展开。
- **出现**：乘法分配律、质因数、通分、多边形内角和、面积公式推导、因式分解。
- **判据**：给一个量，能给出不同的拆法，并说明哪种拆法对当前问题有用。

### E3　度量与单位（用一把尺子量）
- **一句话**：数是“用某个单位去量”的结果；换单位，数变，量不变。
- **碰到**：分数是换了更小的尺子；1 米=100 厘米；1/2 = 2/4。
- **数学**：量纲、比率、分数、测量误差、近似。
- **出现**：通分约分、单位换算、比、百分数、小数、近似与估算、π。
- **判据**：能说出“数变了，量没变”的例子；能指出什么时候两个量不能直接相加（单位不同）。

### E4　平衡与等价（做同样的事，保持不变）
- **一句话**：两边相等；同时做同一件事，仍然相等；只动一边，必须补偿。
- **碰到**：天平歪了，找出该补多少；解方程天平。
- **数学**：等价关系、等式的性质、逆运算、群作用的雏形。
- **出现**：方程、不等式（歪的方向）、通分（等价分数）、比例、杠杆、守恒、公平。
- **判据**：能说清楚“我这一步在两边各做了什么”；故意只动一边时能预测天平歪向哪边。
- **延展**：见 `balance.md`（等式、不等、杠杆、守恒、公平、对称、动态平衡）。

### E5　不变量与变换（变了什么，没变什么）
- **一句话**：做一种变换，总有些东西变了，有些东西没变；找到不变量，问题常常就解了。
- **碰到**：剪拼后面积不变；倒水后体积不变；翻折后长度不变；每走一步奇偶性不变。
- **数学**：不变量、对称群、同余类、守恒律。
- **出现**：面积/体积、全等与相似、轴对称与旋转、奇偶性、同余、游戏必胜策略。
- **判据**：给一个变换，能说出一个不变量；用它解决过一个题目。

### E6　递推与迭代（下一步由上一步决定）
- **一句话**：知道起点和“怎么走一步”，就知道整条路。
- **碰到**：记忆器接成环，数列自己长出来；两辆车每拍走一步。
- **数学**：递推关系、数列、不动点、收敛、动态系统。
- **出现**：数数、等差等比数列、斐波那契、复利、追及、循环小数、细胞自动机、周期（同余钟）。
- **判据**：能把一个情境写成“起点 + 一步规则”；能预测一百步后的状态（找周期或通项）。

### E7　极限与逼近（无限地靠近）
- **一句话**：一个量可以不等于某个值，却无限靠近它；靠近的方式有规律。
- **碰到**：√2 夹逼；0.999…=1；掷骰子越多，平均数越稳。
- **数学**：极限、收敛、大数定律、连续与稠密。
- **出现**：小数与近似、开方、π、概率与频率、圆的面积（多边形逼近）、函数图像。
- **判据**：能说出“为什么不能一步到位，却能任意接近”；能判断一个逼近是在变好还是只是在晃。

### E8　变量与任意性（字母是“任意一个”）
- **一句话**：字母不是未知的某个数，而是“所有数里的任意一个”；式子对所有取值成立才叫恒等。
- **碰到**：变量盒里全绿；n²+n+41 对前 39 个都对，第 40 个不对。
- **数学**：全称量化、代数恒等式、函数。
- **出现**：字母表示数、整式运算、乘法公式、方程与恒等的区别、函数、不等式的解集。
- **判据**：能区分“对某个 x 成立”和“对所有 x 成立”；会用试几个数来排除一个错误的公式。

### E9　规律、猜想与证明（例子够不够）
- **一句话**：例子给证据，推理才给“一定”；一个反例就能推翻。
- **碰到**：猜想与反例器材；证明台把“因为…所以…”连成链。
- **数学**：归纳与演绎、反例、证明、公理体系。
- **出现**：找规律、几何证明、数论、概率直觉的反例（生日悖论）、“改规则的世界”。
- **判据**：学生自己提出猜想并主动找反例；能区分“我试了很多都对”和“我证明了”。
- **证据阶梯**：观察 → 猜想 → 检验 → 找反例 → 解释（为什么）→ 证明 → 迁移。

### E10　对称（同样的结构换个位置）
- **一句话**：一个图形或一个式子，做某些变换后看起来一样。
- **碰到**：折一下重合；二次函数左右一样；a+b=b+a。
- **数学**：对称群、奇偶函数、交换律、对称轴、相似。
- **出现**：轴对称、旋转平移、二次函数、交换律结合律、杨辉三角。
- **判据**：能找出一个图形所有的对称，并用对称简化计算。

### E11　随机与分布（不确定也有结构）
- **一句话**：单次不可预测，大量有分布；分布能被问出问题（期望、公平、风险）。
- **碰到**：两个骰子，7 最多；硬币公平吗；袋子里的比例。
- **数学**：概率、分布、期望、独立、大数定律。
- **出现**：概率、统计图、平均数中位数、公平游戏、抽样。
- **判据**：能先凭直觉猜，再被数据说服或推翻；能设计一个公平的游戏。

### E12　建模与抽象（把现实变成可算的东西）
- **一句话**：从情境里抽出关键量，丢掉无关的，变成式子或图形，再回头解释结果。
- **碰到**：鸡兔同笼变成两条线的交点；行程变成数轴上的两个点。
- **数学**：数学模型、变量选择、单位检验、结果解释与检验。
- **出现**：应用题、函数应用、统计分析、几何建模。
- **判据**：能为同一个情境选不同的模型并比较；能检查答案在原情境里合不合理。

## 三、本质之间的关系

```
对应(E1) ──→ 度量(E3) ──→ 变量(E8) ──→ 函数
   │            │              │
   ▼            ▼              ▼
分解组合(E2) ─→ 平衡(E4) ─→ 不变量(E5) ─→ 对称(E10)
                  │              │
                  ▼              ▼
              递推(E6) ───→ 极限(E7) ──→ 随机(E11)
                  
   证明(E9) 横跨所有：每一条边都可以问“凭什么”
   建模(E12) 横跨所有：每一个应用题都是一次模型选择
```

读法：箭头表示“后者常以前者为基础”。学生在 E4 之前没碰过 E1、E3，解方程就只是套规则。
这个图将来在界面里做成“本质地图”：每个节点按学生掌握程度亮起，点进去是该本质下的实验路线。

## 四、器材的设计原则（从本质倒推）

1. **学生动手的是“作用”，不是“读数”。** 好器材让学生拖、拼、剪、接环、改规则；坏器材只让他调参数读结果。
2. **每个器材至少给一个“违反规则”的办法。** 违反得到的是解释（“平面上做不出来，换球面试试”），不是报错。
3. **同一本质，换器材再碰一次。** 平衡：天平 → 杠杆 → 守恒量杯 → 公平的游戏。学生在不同器材上都说得出“两边在做什么”，才算迁移。
4. **器材要有“藏起来的真相”。** 解方程天平里盒子的重量是藏着的，学生只能通过操作逼近它；这是实验，不是填空。
5. **器材之间靠值类型连接。** 要让本质流动，值类型必须丰富：数、分数、分布、函数；将来加 点线（几何）、表达式（代数）、集合与关系。

## 五、“真懂”的判定（取代只看做对）

对每个本质，系统要记录三层证据：

| 层 | 看什么 | 例 |
|---|---|---|
| 做到 | 在本质对应的题里通关 | 解方程天平 3 题满分 |
| 解释 | 能说出“两边在做什么” | 选择题：“你这一步的作用是——”；或排序“理由链” |
| 迁移 | 在**没提示**的新场景里用上 | 杠杆题里自己想到“力×距离”两边相等 |

只有三层都有，这个本质才标为“掌握”。现有的评分系统（里程碑、提示层级、陷阱）负责“做到”；“解释”和“迁移”要新增。

## 六、数据模型改动（给内核）

- 器材定义新增 `essence: ['E4', 'E6']`（可多个），lint 要求每个器材至少声明一个。
- 题目定义新增 `essence`、`probe`（解释题）和 `transfer`（指向同本质的另一个题）。
- `U.Review.summarize` 改成**按本质汇总**，而不只是按题。
- 本质目录自身放 `js/core/essences.js`：id、名称、一句话、前置本质、描述文本。
- 界面：左边“实验库”增加“本质地图”视图；学习报告增加“每种本质：做到/解释/迁移”。

## 七、按本质排的建设路线

| 优先 | 本质 | 要做的东西 | 依赖的新能力 |
|---|---|---|---|
| 1 | E4 平衡 | 解方程天平（括号、分数）、不等式天平、杠杆、守恒量杯、公平游戏 | `hidden` 属性（已有）；共享变量（方程组） |
| 2 | E9 证明 | 学生自己写猜想（和学生出题打通）、证明台（理由链） | 本质的“解释”层；理由卡片数据结构 |
| 3 | E5 不变量 | 剪拼、折叠、奇偶性棋盘 | 点线/多边形值类型 |
| 4 | E8 变量 | 变量盒扩展（符号展开、因式分解）、函数画板 | 表达式值类型 |
| 5 | E6 递推 | 细胞自动机、斐波那契与复利、周期 | 无（现有记忆器可扩展） |
| 6 | E2 / E3 | 分解组合（质因数树、面积累加）、单位换算 | 无 |
| 7 | E7 极限 | 夹逼数轴、圆的多边形逼近 | 无限放大的数轴 |
| 8 | E11 随机 | 博弈器材、期望、生日悖论 | 无 |
| 9 | E10 对称 | 折叠、旋转、奇偶函数 | 点线值类型 |
| 10 | E12 建模 | 应用题集（工程、浓度、年龄）、模型选择题 | 无 |
| 11 | E1 对应 | 一一对应配对板、无穷旅馆 | 集合值类型 |

排序的理由：E4 已有基础，做深最便宜；E9 是让实验室从“演示”变成“探索未知”的关键；E5 和 E8 打开几何和代数的新天地，但要加值类型，放在中段。

## 九、诚实的缺口

- 本质目录目前只是文字，内核还不认识它；器材没有 `essence` 字段，界面没有本质地图。
- “解释”和“迁移”两层证据没有实现，学生的掌握还只看“做到”。
- 一部分本质（E1 对应、E7 极限、E10 对称、E12 建模）几乎没有器材。
- 几何的核心器材（剪拼、折叠）依赖点线值类型，没有它做不了。
- 本质的划分本身可能需要调整。这十二种是第一版，应该让更多题目走一遍后再修。
