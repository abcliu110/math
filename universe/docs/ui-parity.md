自动验证：`node tests/ui.js`（无头浏览器，24 项，含 0 控制台报错）。

## 新版比旧版多的

- **世界时钟条**：⏮ ▶ ⏭、0.5×/1×/4×/20×、拍数与秒数。旧版没有统一的时间。
- **属性即端口**：每台器材每个可写属性都能被别的器材驱动（拖线放到卡片左边的药丸上）。
- **连线上的值气泡**、**拖线时的可行性提示**。
- **预测 → 动手 → 对比**，**陷阱识别**，**“你找到了一种新做法”**。
- 错误不弹窗：被拒绝的操作用一句人话解释原因（环路、单位不同、类型不匹配、属性被驱动）。

## 没做到的（如实）

- 器材 37 种（旧版 123 种）；题目 32 道（旧版约 394 个编号）。内核已能容纳，缺的是内容，按 `docs/design-v2.md` 第 8 节阶段推进。
- 没有“容器/子台面”、器材包懒加载、证据阶梯（只有“例证”这一级）。
- 没有浅色主题、没有触摸双指缩放。
- 学生出题（凑数题）已做；更一般的出题未做。
- 家长端/老师端：学习报告（菜单 → 学习报告）与“今天该复习”已做（`js/core/review.js` 从事件流现算）；老师布置探究作业、家长单独入口尚未做。
