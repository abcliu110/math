## 一、旋钮长出图像（记录仪）

### 孩子看到什么
操作台下面多一条折叠栏“📈 记下来”。打开后：
1. 选一个**旋钮**（横轴，比如“总腿数”）和一个**结果**（纵轴，比如“兔几只”）。
2. 孩子每在台面上拧一次旋钮、得到一个结果，小图上就多一个点。**不会自动帮他画满。**
3. 记了 3 个点以后，拧之前先让他**猜**：下一个点在哪？他拖一个虚点，然后再拧，看猜得准不准。
4. 记了 5 个点以后，才出现“全部试一遍”：一下子画出所有点。

### 为什么这能长出东西
真正有意思的不是“是一条直线”，而是**图上的意外**：

| 图上的样子 | 在哪里碰到 | 引出来的数学 |
|---|---|---|
| 直线，但**隔一个缺一个点** | 鸡兔同笼：头数 10 固定，总腿数从 20 拧到 40 | 腿数是单数时凑不出来：图上的洞就是“凑不出来” |
| 往下走的直线 | 鸡兔同笼：总腿数固定，拧头数 | 每多 1 个头，兔少 1 只：斜率是负的 |
| 中间最高的拱 | 周长固定的长方形，拧长 | 最大面积在正方形：接上**极端主线** |
| 台阶 | 分一分：拧总数，看每人几个（商） | 余数在台阶上一格一格地涨 |
| 锯齿 | 分一分：拧总数，看余数 | 周期，接上同余钟 |

第三层追问就问图：“每多 1，多几？”“为什么缺这些点？”“最高点在哪，为什么是它？”

### 做法（不改内核）
- 每台器材的 `compute(c)` 只依赖 `props`，是纯函数；整数旋钮都声明成 `I(min, max, …)`，结果都是 `kind: 'num'` 的输出。所以记录仪可以**对任何操作台通用**：监听某个 prop 的变化，读某个 output，存一对数。
- 只能选出题人允许的轴。题目里写：`graph: { x: 'T', y: 'b', keep: { n: 10 } }`；其它 prop 在记录时锁住，避免两个旋钮一起变、点就乱了。
- “全部试一遍”就是在 x 的范围里逐个调用 `compute`，拿不到合法结果的地方画空心圈（洞）。
- 新的里程碑输出：`pts`（记了几个点）、`guess`（猜对几次，误差在 1 格以内算对）、`rule`（追问里选对的规律）。

### 第一批（四台，都已有操作台）
1. `swapbench` 总腿数 → 兔几只（直线带洞）
2. `swapbench` 头数 → 兔几只（往下的直线）
3. 周长固定的长方形：长 → 面积（拱）。用的是 `areabench` 的篱笆围地（已做）
4. `groupbench` 总数 → 商、总数 → 余数（台阶、锯齿）

### 这一版不做
- 两个旋钮一起变（三维）
- 孩子自己写公式拟合（`fitbench` 已经有拖直线）
- 小数旋钮

## 二、解法图鉴

### 孩子看到什么
实验库里多一个“📖 解法图鉴”。一页一道**母题**，比如鸡兔同笼，每页有一排格子，每格一种做法：

| 格子 | 用哪台 | 现在有没有 |
|---|---|---|
| 假设法：先当全是鸡 | `swapbench` | 有 |
| 列表 / 一个一个试 | `swapbench` 的试过记录 或 `twoways` 右边 | 有 |
| 两架天平（相减） | `systembench` | 有 |
| 抬腿法：每只都抬起两条腿 | `swapbench` 的“每个都少算” | 有 |
| 分步算式：70 → 24 → 12 | 运算器（`content-g4` 的 `g4-chicken-rabbit-core`） | 有 |
| 画面积图：头数 × 2 是底 | `areamodel` 能画长方形，但没有鸡兔题 | **没有** |
| 方程 | `equation` 没有鸡兔题 | **没有** |

查过的现状：已有的鸡兔题用的数不统一（35 头 94 腿、8 头 26 腿、10 头 26 腿都有）。第一页定成 **35 个头、94 条腿**（`content-g4`、`zz-benches` 已经用它），其它格子各加一道同数的变体。

- 格子一开始是灰的，用那种方法做对一次就点亮。
- **每一格都用同一组数**（8 个头、26 条腿）。孩子会看见：方法完全不一样，答案都是兔 5 只。
- 点亮两格以后，两格中间出现一座桥：点它，进 `twoways` 式的对照，把两种做法的步骤连起来。**桥就是以后地图上的路**，先在图鉴里长出来。
- 一页至少点亮 3 格，再追问：“换成 100 个头、316 条腿，你选哪种？为什么？”没有标准答案，记进研究本。

### 做法
- 题目加两个字段：`family: 'chick-rabbit'`（母题）、`way: 'assume' | 'table' | 'system' | …`（哪种做法）。图鉴面板就按这两个字段把已有题目归到格子里，**第一页几乎不用新题**。
- 同一页的题必须用同一组数，在参考解测试里加一条检查：同 family 的题，答案一样。
- 点亮用现有的星星记录：这格对应的题拿到 ≥1 星就算点亮。

### 第一页之后
母题候选：和差问题、植树问题、盈亏问题（`surplusbench` 已有）、行程相遇。每一页都先数一数**已有**几种做法，凑不到 3 种的先不开。

## 顺序建议

1. **图鉴第一页（鸡兔同笼）**：主要是给已有题加字段，再加一个面板，最省事，而且马上能看出“连起来”的效果。
2. **记录仪接在 `swapbench` 上**：两种图（带洞的直线、往下的直线），正好挂到鸡兔同笼那一页的第三层追问里。
3. 再把记录仪推到 `groupbench` 和长方形面积；图鉴再开第二页。（都已做；第二页选了连加，不是候选里的和差、植树、盈亏：那几道已有的做法凑不到 3 种）

每一步都按老规矩：参考解、界面测试、完整验证“全部通过。”再提交。

## 要你拍板的
- 图鉴第一页缺的“面积图”和“方程”两格：在 `areamodel`、`equation` 上各补一道题，还是先空着（显示“还没发现”）？我倾向补上：都是已有操作台，不用新做器材。
- 记录仪默认要不要藏起来，只在第三层追问时出现？我倾向**藏起来**，免得低年级一上来就看到坐标图。
