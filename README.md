# 数学小宇宙

小学 1–6 + 初中 7–9 的数学 App 原型：**可视化优先，复杂变简单，能动手就不只看**。

> 目标：每个抽象概念都能拖、能切、能调。先动手摆一摆，再看图想一想，最后才写算式。
> 原则：CPA（实物 → 图像 → 符号）、互动优先、**教 WHY 也教 HOW**（每个概念都要讲清楚为什么，不只是步骤）、版权上只学背后的想法，再用自己的话、图和例子重写，不直接复制任何教程、图片或代码。

## 现在有什么

这是一个**首页原型**，不是完整课程。能玩的部分是真的，内容部分还是骨架。

- `apps/web/index.html` — 首页：标题、年级选择器（1–9 年级）、学习路径、三个互动演示、进度与错题本（占位）、下一步
- `apps/web/styles.css` — 响应式样式：桌面 ≥1024px 三栏，平板触屏大按钮，768px 以下单列
- `apps/web/app.js` — 年级数据 + 三个演示的逻辑，全部原创、无外部依赖

### 三个互动演示（都能玩）

1. **P1 分数切一切 + 数轴**（3–5 年级）：选分母、拖分子、点圆饼、拖数轴上的点；圆饼、数轴、等值分数和小数一起变。
2. **P2 天平解方程**（5–7 年级）：解 `3x + 5 = 20`。两边同时 −5、两边同时 ÷3 保持平衡；只动一边会歪给你看。
3. **P3 函数滑杆**（7–8 年级）：拖 `k`（每公里多少钱）和 `b`（起步价），`y = kx + b` 的直线、表格和打车费故事一起变。

### 为什么（WHY，不只是 HOW）

每个演示下面都有一段大白话的“为什么”，能用图讲的就用图讲。首页还有三个能动手验证为什么的小实验：进位（10 个一 = 1 个十）、分数除法（3/4 里有几个 1/4，所以倒数相乘）、面积公式（长 × 宽就是数小方块：几行、每行几个）。

### 年级内容

首页的年级面板按人教版常规顺序列了每个年级的单元和可视化方式（1–9 年级）。**这只是骨架，不是全部内容**——Iris 的要求是 1–6 年级要全部知识点，不是摘要。完整内容要按教材逐册核对章节顺序后，再一册一册填进 `content/`。

## 本地预览

不需要安装、不需要构建，直接用浏览器打开：

```bash
# 方法一：直接打开文件
open apps/web/index.html

# 方法二：本地服务器（推荐，平板/桌面都可访问同一局域网地址）
python3 -m http.server 8000
# 再打开 http://localhost:8000/apps/web/
```
